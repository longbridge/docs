<p>基金投資涉及凈值波動、資金狀態、持倉價值和收益計算等多個核心概念，理解這些術語有助於投資者清晰掌握資產動態和收益情況。</p><h3>日漲跌幅</h3><p>基金公司按照基金每日持有的股票、債券資產在扣掉費用後實際計算出的淨值與上一交易日的淨值漲幅差，計算公式為：漲跌幅（%）=（當前最新淨值 - 上個交易日淨值）/上個交易日淨值 *100%。</p><h3>買入待確認資金</h3><p>根據基金交易規則，從發起購買申請起直至份額確認，一般需要 2-3 個工作日（是指需要排除輝立證券及基金公司假期之外的工作日），在確認購買申請成功之前，申請的資金為待確認狀態，即待確認資金。</p><h3>賣出待入賬金額（凍結份額）</h3><p>基金賣出成功後，相應資金還未到用戶的賬戶的部分（包含當前基金賣出的掛單、未確認份額的凍結部分）。</p><h3>持有份額</h3><p>當前基金持倉份額。</p><h3>單位淨值</h3><p>每份額基金當日的價值。是基金淨資產除以基金總份額，得出的每份額基金當日的價值。每個交易日根據基金所投資證券市場收盤價計算出基金總資產價值，扣除基金當日的各類成本及費用後，得出該基金當日的資產淨值。除以基金當日所發生在外的基金單位總數，就是每單位基金淨值。</p><h3>基金總額</h3><p>計算公式：基金總額= 申購待確認金額 + 持有金額 + 賣出待入賬金額。</p><h3>最新收益</h3><p>計算公式：最新收益=（對應日期淨值 - 上一交易日淨值）* 對應日期的份額 + 對應日期現金分紅。</p><h3>持有收益</h3><p>計算公式：持有收益= 持有金額 - 持倉成本。</p><h3>持有金額</h3><p>計算公式：持有金額= 持有份額 * 當前最新基金淨值。</p><h3>累計收益</h3><p>每日收益的總和。</p><p> </p><p><strong>關鍵要點</strong>：</p><ul><li>資金與份額狀態<ul><li>買入待確認資金：提交申購申請後、份額確認前的資金，處於待確認狀態。</li><li>賣出待入賬金額：賣出申請成功但資金尚未到賬的金額。</li><li>持有份額：您當前實際持倉份額。</li></ul></li><li>凈值與價值計算<ul><li>單位凈值：每份基金的當日價值，由基金總資產扣除費用後計算得出。</li><li>持有金額：持有份額 × 當前最新凈值，代表您持倉的當前總市值。</li><li>基金總額：申購待確認金額 + 持有金額 + 賣出待入賬金額，是您在該基金上的全部資產總和。</li></ul></li><li>收益計算<ul><li>日漲跌幅：衡量基金凈值每日的相對變化率。</li><li>最新收益：（對應日期凈值 - 上一交易日凈值）* 對應日期的份額 + 對應日期現金分紅</li><li>持有收益：持有金額 - 持倉成本，代表您持有該基金以來的總浮動盈虧。</li><li>累計收益：所有每日收益的總和，是您投資該基金的最終總回報。</li></ul></li></ul><p> </p><p><strong>免責聲明</strong></p><p><i>本文僅作參考，不構成任何投資建議。</i></p>
