<p>註銷賬號處理流程如下：<br/>在註銷前，請您留意以下事項：<br/> </p><ol><li>資產結清：確保賬戶內無待結算資產、無負債，且已解除所有第三方綁定關係。</li><li>數據清空：註銷後，您的身份信息、賬戶資料及交易記錄等將被清空且無法找回。</li><li>權益放棄：註銷視為放棄未來可能產生的權益（如新股退票等）。</li><li>註冊限制：賬號註銷後的 90 天內，無法使用當前手機號再次註冊。</li></ol><ul><li>已完成開戶：填寫註銷申請表：<a href="https://pub.lbkrs.com/files/202602/LS5FyJKJf5ZmQAVT/___20260225.pdf">https://pub.lbkrs.com/files/202602/LS5FyJKJf5ZmQAVT/___20260225.pdf</a> 發送至 service@longbridge.hk，預計 7 個工作日內處理。註銷前需結清所有資產、解除 eDDA/銀證轉賬等第三方綁定。賬戶內現金可放棄處理，但賬戶內股票不可放棄，可選擇以實物方式提取港股，或轉出至其他證券公司。</li><li>未完成開戶：請聯繫客服協助。</li></ul><p> </p><p><i>本文僅供參考。</i></p>
