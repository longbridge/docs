<p>到期日，若 FCN 掛鈎標的<strong>收市價跌穿行使價</strong>、且存續期內<strong>曾觸發敲入（Knock-in）</strong>，投資者便會「接貨」——按<strong>行使價以本金買入</strong>該標的；<strong>若產品未設敲入界限</strong>，則只看到期日收市價是否低於行使價，<strong>低於即接貨</strong>。</p>
