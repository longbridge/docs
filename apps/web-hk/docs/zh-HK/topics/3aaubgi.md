<p>本文將快速解答關於餘額通常見的疑問。</p><p><strong>1. 餘額通有何特色？</strong></p><ul><li>隨心炒股：股票交易不受限製，無需擔心錯過市場機會。（閑置資金獲取潛在收益的同時，資金隨時可用（實時可用，T+1 可取））</li><li>閑錢增值：為閑置資金提供潛在增值收益，股市休市錢不休。（運用專業的財富管理能力，甄選優質的投資品種。）</li><li>一勞永逸：一次簽約、自動申購，無需手動。</li><li>貨基打底：餘額通主要投資於流動性良好的低風險低波動率的貨幣基金。*</li><li>更低的起購：低門檻，單賬戶無資金上限。</li></ul><p><strong>2.餘額通可以手動贖回嗎？</strong></p><p>餘額通支持手動贖回，客戶至餘額通頁面可以隨時申請贖回，若交易日上午 9:10 之前提交贖回，則 3 個自然日內贖回款不會自動轉入餘額通（若提交贖回時間晚於交易日 T 日上午 9:10 則 T+3 日內贖回款不會自動轉入餘額通），贖回後可立即用於股票交易，認購新股，貨幣兌換，出金。贖回的資金最晚 T+1 日到賬。除此外，餘額通根據你的證券賬戶餘額情況進行自動申購或自動贖回：</p><ul><li>自動申購：僅需設置一次，設置成功後，每日固定時間將現金自動買入餘額通底層的貨幣基金，零申購費用，資金不閑置。</li><li>自動贖回：餘額通支持可直接用於股票交易，每日收盤結算後繫統將根據您的證券賬戶欠款情況自動贖回餘額通底層的貨幣基金進行還款，零自動贖回費用。</li></ul><p><strong>3. 餘額通可以直接用於貨幣兌換和出金嗎？</strong></p><p>出金申請中系統幫客戶贖回對應額度的餘額通貨幣基金，根據提取資金申請時間不同，T 或 T+1 日出金。若申請貨幣兌換或還款，則需要客戶手動贖回餘額通對應幣種的貨幣基金，贖回到賬後即可進行貨幣兌換和還款。</p><p><strong>4. 餘額通支持新股認購嗎？</strong></p><p>長橋證券會在個別情況下支持客戶用餘額通打新，但是客戶存在無法直接用餘額通打新的可能，用戶申購時間晚於認購截止日的前一個交易日上午 9:30，由於餘額通贖回金額到賬時間晚於認購截止日，存在無法用餘額通直接打新的情況。因此，建議客戶與客服人員確認和盡早申購新股以免錯過打新機會。</p><p><strong>5. 餘額通可以用於轉倉費用的扣除嗎？</strong></p><p>暫不支持通過餘額通來支付轉倉費用，如客戶現金均轉入餘額通後發生轉倉費用，則將使用融資支付轉倉費用，融資利息可前往<strong>我的</strong> &gt; <strong>我的費率</strong>中查看。</p><p><strong>6. 如何計算收益？</strong></p><p>老版本餘額通，香港交易日上午 9:10 之前轉入，當日確認份額計算收益，下一個交易日可查看收益情况，9:10 之後轉入則順延一個交易日。新版本餘額通，香港交易日上午 8:30 之前轉入，當日確認份額計算收益，下一個交易日可查看收益情况，8:30 之後轉入則順延一個交易日。</p><p>使用新版本餘額通舉例：</p><p>情景 1：轉入申請時間為週一上午 8:00，則週一就可以確認份額計算收益，在週二可查看收益情况。</p><p>情景 2：轉入申請時間為週一 15:30，則週二可以確認份額計算收益，在週三可查看收益情况。新版本正在逐步開放中，如果在單個幣種下有多只基金可選擇，說明您已經在使用新版本餘額通。</p><p><strong>7. 關閉餘額通服務後，錢要多久到賬？</strong></p><p>當資金已轉入餘額通還未確認份額或者客戶已持倉餘額通，此時手動關閉餘額通服務，系統將在最近一個交易日進行贖回，贖回的資金最晚 T+1 日到賬。</p><p> </p><p style="margin-left: 0pt"><i>* 投資涉及風險，投資者應仔細閱讀基金資訊及相關文件 (包括其風險因素)。基金産品的價格可升亦可跌，可能在短時間內大幅變動，投資者或無法取回其投資於基金的金額，基金過往的表現不能預示日後的表現。</i></p><p><strong>免責聲明</strong></p><p><i>本文僅作參考，不構成任何投資建議。</i></p>
