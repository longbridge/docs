<p>以下是關於追繳保證金的詳細介紹和案例。</p><p>當股權資產低於維持的水平時，本公司會發出追繳保證金通知。 客戶必須在收到通知起 3 個交易日內（包括收到通知當日）清繳追繳保證金差額。<strong>追繳保證金將會高於維持保證金和股權資產的差額。</strong></p><p><strong>注意</strong>： 在以下高風險情況下，為控制賬户整體風險，本公司可能無法等待完整 3 個交易日，而會立即採取強制平倉等措施：</p><ul><li><strong>持有末日期權</strong>：由於末日期權價值可能在短時間內劇烈波動或歸零，導致賬户資產迅速惡化。</li><li><strong>市場極端波動</strong>：當標的資產價格出現急劇波動，致使賬户資產快速跌破強平線。</li><li><strong>其他流動性風險</strong>：本公司判斷賬户存在無法在 3 日內覆蓋虧損的較高風險時。</li></ul><p> </p><h4>示例：追繳保證金案例</h4><blockquote><p>客戶存入$10,000 現金及價值$5,000 的 A 股票（IM：30%, MM：25%），並購買了價值$25,000 的 B 股票（IM：50%, MM：45%）。假設 B 股票的市值跌至$19,500。</p></blockquote><p>客戶購入股票後， B 股票的市值下跌後， 客戶持倉為下</p><figure class="table"><table><colgroup><col style="width: 24.06%"/><col style="width: 75.94%"/></colgroup><tbody><tr><th>現金結欠</th><td>HKD 15,000</td></tr><tr><th>持倉初始保證金</th><td>HKD 11,250 (HKD 5,000 X 30% + HKD 19,500 X 50%)</td></tr><tr><th>持倉維持保證金</th><td>HKD 10,025 (HKD 5,000 X 25% + HKD 19,500 X 45%)</td></tr><tr><th>股權資產</th><td>HKD 9,500</td></tr><tr><th>追繳保證金 *</th><td>HKD 1,750</td></tr></tbody></table></figure><p>客戶需在指定日期或之前使其賬戶的股權資產達至保證金要求。</p><p>如客戶選擇賣出證券，所需賣出的市值則不多於初始保證金和股權資產的差額/初始保證金系數 (IM Ratio)</p><p><strong>當股權資產低於強平保證金時，必需立即清繳追繳保證金差額， 否則持倉可能被即時強平。</strong></p><p><strong>注：實際追繳金額可能較高，視乎股票性質和公司政策而定。</strong></p><p> </p><p><strong>關鍵要點</strong>：</p><ul><li>觸發條件：股權資產價值低於維持保證金水平。</li><li>追繳金額：追繳金額通常高於維持保證金與股權資產的差額。</li><li>處理時限：收到通知後需在 3 個交易日內補足資金或減倉。</li></ul><p> </p><p><strong>免責聲明</strong></p><p><i>本文僅供參考，不構成任何投資建議。</i></p>
