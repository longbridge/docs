<h2>一、什麼是圖表交易？</h2><p>圖表交易即用戶可同時在圖表上進行看盤、分析和下單交易。通過分析價格走勢、交易量以及其他市場數據，交易者可以識別出潛在的買入或賣出機會，並直接在圖表上快速進行交易操作。</p><p>圖表交易的特色包括以下幾點：</p><ul><li><strong>圖表上快捷下單</strong>：用戶可以直接在圖表上進行下單操作，簡化了交易流程，提高了操作效率。</li><li><strong>直接拖動改单</strong>：通過拖動價格線，用戶可以快速修改已有訂單，方便靈活地調整交易策略。</li><li><strong>止盈止損設置</strong>：用戶可以在下單時直接附加止盈和止損單，幫助管理風險，確保交易更加安全可靠。</li><li><strong>可視化持倉信息</strong>：系統提供直觀的持倉信息展示，用戶可以清晰地查看價格委託線與現價的差距，便於及時做出交易決策。</li><li><strong>一鍵平倉</strong>：支持一鍵平倉功能，用戶可以快速關閉當前股票的持倉，方便快捷地執行交易決策。</li></ul><h2>二、如何開始圖表交易？</h2><p>可以直接在圖表功能上開啟圖表交易，有兩個快捷入口：</p><p>（1）<strong>點擊圖表頂部的 “打開圖表交易” 按鈕</strong>：點擊該按鈕後，圖表將切換至圖表下單模式；</p><p>（2）<strong>在圖表中滑動價格後點擊右側價格區域的 “+” 按鈕</strong>：在圖表中滑動價格後，右側行情圖表價格區域會出現 “+”，點擊該按鈕可喚起切換圖表下單提示。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/92e6dc7e32ffed4399d08f2e446bfb62"/></figure><p><span style="color: rgb(216,57,49)">說明：為保障用戶資產數據安全，進入圖表下單前需驗證交易密碼。如已驗證則自動進入圖表下單模式；如密碼超時失效，將退出圖表下單模式，需重新驗證。</span></p><h2>三、界面說明</h2><p><span style="color: rgb(216,57,49)"><strong>注意：</strong>由於圖表模式的設置限制，Trading View 模式下的圖表無法顯示止盈止損的委託線，也無法直接拖動止盈止損單。為了使用完整的功能，建議切換到經典模式圖表。</span></p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/30cf2606492ca425cd5173def871ff6e"/></figure><h2>四、圖表交易</h2><h3>1. 設置交易數量</h3><p>圖表交易開始前，需要提前設置交易數量，首次默認為一手，使用戶可通過快捷鍵或手動輸入進行修改；委託數量支持 1/2、1/3、1/4、全倉選擇，委託數量數據根據用戶當前購買力進行計算匹配。</p><p>如設置交易數量為 100，那麼後續的下單操作交易數量都會默認是 100。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/9e6fa149953d937bb42bdf3752d4443f"/></figure><h3>2. 頭部快捷交易</h3><p>行情圖表頂部可操作快捷市價委託、快捷買一、快捷賣一委託；</p><p>設置委託數量後，點擊市價買入/賣出按鈕，將直接提交一筆市價委託訂單；</p><p>為確保訂單安全，已開啟下單二次確認的用戶，會出現訂單二次確認窗口（由於該設置屬於自定義行為，需要前往「設置 - 交易設置」中進行檢查）；</p><p>若想要喚起通用交易組件，可點擊其他買入、其他賣出喚起通用的交易組件進行委託下單</p><p><strong>說明</strong>：如當前標的委託數量為 0 時，按鈕將置灰不可點擊，需重新輸入數量後進行下單。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/a514c259c8fb8b972bffed5401a21423"/></figure><h3>3. 圖表 K 線下單</h3><p>可在圖表中選擇價格快速委託。系統右側價格區域將實時跟隨滑鼠滑動顯示當前選中的價格，通過點擊右側價格區域的 “+”，操作委託下單。目前系統通過圖表上選擇價格下單僅支持限價單（增強限價單）。</p><p>說明：</p><ul><li>為了確保訂單能提報，會存在選擇的價格與最終下單價格略微不一致的情況，目前均按照價格最小單位向上取整。（可參考：下單組件價格輸入框點擊 “-/+” 號時價格最小變動位值。）</li><li>美股圖表下單不支持夜盤交易，需要通過通用的交易組件來進行夜盤下單</li></ul><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/14900682f8e37b7cc3d651b0ec3433ce"/></figure><h3>4. 改單</h3><p>圖表下單模式下，支持三個改單入口：</p><h4>（1）直接拖動價格改單</h4><p>第一個是最便捷的，也是最方便的，可直接拖動改價：可按住委託線在圖表上進行上下拖動，滑鼠鬆開後，將提交改單，改單成功後委託線將停留在改單後的價格上。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/a570b337870bbce3194860c82527f298"/></figure><h4>（2）委託單詳情頁改單</h4><p>單擊委託線數量區域：如需修改委託數量，可單擊委託線上數量區域可跳轉至下單組件，下單組件會默認攜帶委託信息，支持對委託價格、委託數量進行修改，修改後直接提交改單，改單成功後圖表將更新訂單數據。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/02f298ae94b7ec4cfbd530a771f649e2"/></figure><h4>（3）當日訂單列表改單</h4><p>當日訂單列表包含所有當日的委託單，可一目了然查看所有的當日訂單。若支持改單的訂單，在訂單模塊中會有改單圖標，可點擊該圖標進入下單組件，對訂單價格和數量進行修改。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/69c3b99b953e5c0b0bcbf94ff3faee57"/></figure><h3>5. 撤單操作</h3><h4>（1）單筆撤單</h4><p>單筆撤單存在兩個入口：</p><p>圖表撤單：在委託線上直接點擊 “X”，可進行快捷撤單；如已關閉撤單二次提示，可在「設置 - 交易設置」中重新打開；</p><p>當日訂單模塊撤單：展開訂單列表後，可點擊撤單圖標進行快捷撤單。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/169f6a88b9a152886e73bcd75d6a461a"/></figure><h4>（2）批量撤單</h4><p>點擊頭部來進行快速批量撤單，包括：撤銷全部、撤銷買單、撤銷賣單</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/c6224032cef9db0aac5900d67ffe926b"/></figure><h3>6. <strong>止盈止損附加單</strong></h3><h4>（1）圖表中直接下單、改单、撤單</h4><p>在圖表中設置了主單之後，可直接點擊「TP」、「SL」標籤進行拖動，來快速設置止盈止損單。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/c83b25776a4d9137565ae87bc4a2c168"/></figure><h4>（2）附加單設置</h4><p>1、除了在圖表中直接操作，也可以提前設置好止盈止損附加單設置，方便下單的時候直接委託，提高交易效率。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/66b3f5d2d662468c26657fed5488a9bc"/></figure><p>2.點擊圖表交易的附加單設置，可設置止盈止損單，目前支持 3 種設置：</p><p>檔位，即止盈停損相對於最新價的檔位；</p><p>價差，即停盈停損相對於最新價的價差；</p><p>價格，即直接設定止盈觸發價，停損觸發價；</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/b53c31b9d89003cac7a5385c0ab224af"/></figure><p>3、舉例：目前最新價為 278.20，下單委託價為 278.00，股票價差為 0.01。</p><ul><li>選擇了檔位，停盈為 5，停損為 2，即停減價=278.00+5*0.01=278.05，停損價=278.00-2*0.01=277.98；</li><li>選擇了價差，停損為 5，停損為 2，即停減價=278.00+5=283，停損價=278.00-2=276；</li><li>選擇了價格，停盈為 270，停損為 285，即停減價=270，停損價=285</li></ul><p>4、設定了停盈停損價之後，下單時，可直接勾選需要設定的附加單。</p><p>5、下完单后，可在图表中直接查看到当前订单关联的止盈和止损单。</p><h3>7. 持倉信息</h3><p>持倉信息存在圖表兩處可快速查看：</p><p>頭部固定的持倉信息位置，包括持倉數量、持倉成本價、收益金額、收益率信息</p><p>圖表中也可以直接查看持倉線，包括持倉成本價、收益金額和數量，可以清晰地查看價格委託線與現價的差距，便於及時做出交易決策。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/defc6d37205d2e05944516e29e04b0a2"/></figure><h3>8. 快速平倉</h3><p>若存在股票價格快速波動，需要平倉，可點擊「平倉」按鈕來快速平倉。平倉默認為市價單，也可自行修改後再下單。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/8482cf03667ae72c1b04d3c58c7deeba"/></figure><h3>9. 當日訂單模塊</h3><p>有時候受價格限制，圖表上可能看不全所有的訂單信息，容易漏掉，可通過當日訂單模塊來快速查看所有的訂單信息，並且也可以進行撤單、改單操作。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/7c82814ec23c8a091288f12af50ab56a"/></figure><h2>五、圖表交易設置</h2><p>目前針對圖表交易中的功能，支持特別設置，可點擊圖表的右上角設置按鈕，進行單獨設置。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/29e7cd62b33d823579949f5a754707e0"/></figure>
