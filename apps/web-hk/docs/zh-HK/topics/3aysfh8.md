<p>長橋綜合賬戶是一個讓您能夠靈活管理您的投資，並在您需要時利用杠桿進行交易的交易賬戶。 您可以選擇通過指定證券放在您的賬戶中作為抵押品，通過保證金融資提高您的投資購買力。</p><p>賬戶的融資額度會根據您存入的現金或者轉倉情況自動評估。 如需調整，請登錄長橋 App &gt; <strong>資產</strong> &gt; <strong>融資狀態</strong>申請，或者聯系您的客戶經理。</p><h2>1. 保證金</h2><ul><li><strong>初始保證金（IM）</strong>：建倉時需存入的保證金要求</li><li><strong>維持保證金（MM）</strong>：股權資產需維持的水平</li><li><strong>平倉保證金（FM）</strong>：當股權資產低於此水平時， 持倉可能被即時強平</li><li><strong>IM/MM/FM 要求</strong> = 加總 (個人投資產品的市值 x 相應的保證金系數)</li></ul><h2>2. 保證金要求</h2><p><strong>股權資產 </strong>= 現金餘額 (分類賬)+ 投資組合總市值</p><h3>可用資金</h3><ul><li><strong>可用資金（包含融資）</strong>= 股權資產 - 初始保證金要求 - 凍結資金</li><li><strong>最大購買力</strong> = 可用資金 / 初始保證金 (IM)</li></ul><p>結欠不得超過融資額度</p><p><strong>示例：</strong></p><blockquote><p>客戶存入$10,000 現金，並購入初始保證金系數（IM ratio）為 30% 的股票，賬戶融資額度為$20,000</p></blockquote><p>最大購買力 = $10,000 / 30% = $33,333</p><p>假設賬戶融資額度為$20,000，因此該賬戶實際最多只能購買$30,000 該股票（$10,000 為現金，$20,000 為融資）</p><h3>追繳保證金 (Margin Call)</h3><p>追繳保證金將會高於維持保證金和股權資產的差額。</p><p>當股權資產低於維持的水平時，本公司會發出追繳保證金通知。客戶必須在收到通知起 3 個交易日內（包括收到通知當日）清繳追繳保證金差額。</p><p><strong>示例：追繳保證金案例</strong></p><blockquote><p>客戶存入$10,000 現金及價值$5,000 的 A 股票（IM：30%, MM：25%），並購買了價值$25,000 的 B 股票（IM：50%, MM：45%）。假設 B 股票的市值跌至$19,500。</p></blockquote><p>客戶購入股票後， B 股票的市值下跌後， 客戶持倉為下</p><figure class="table"><table><colgroup><col style="width: 24.06%"/><col style="width: 75.94%"/></colgroup><tbody><tr><th>現金結欠</th><td>HKD 15,000</td></tr><tr><th>持倉初始保證金</th><td>HKD 11,250 (HKD 5,000 X 30% + HKD 19,500 X 50%)</td></tr><tr><th>持倉維持保證金</th><td>HKD 10,025 (HKD 5,000 X 25% + HKD 19,500 X 45%)</td></tr><tr><th>股權資產</th><td>HKD 9,500</td></tr><tr><th>追繳保證金</th><td>HKD 1,750</td></tr></tbody></table></figure><p>客戶需在指定日期或之前使其賬戶的股權資產達至保證金要求。</p><p>如客戶選擇賣出證券，所需賣出的市值則不多於初始保證金和股權資產的差額/初始保證金系數 (IM Ratio)</p><p><strong>當股權資產低於強平保證金時，必需立即清繳追繳保證金差額， 否則持倉可能被即時強平。</strong></p><blockquote><p>實際追繳金額可能較高，視乎股票性質和公司政策而定。</p></blockquote><h2>3. 餘額資金管理服務</h2><p>您可選擇加入餘額通管理服務，餘額通是長橋證券（香港）有限公司推出的一款閒置資金理財產品。為客戶提供現金增值服務，既滿足客戶隨時買股票的需求，又能為客戶的閒置資金創造收益。加入後，您多餘的港幣及美元資金將酌情用於投資貨幣市場基金。</p><p>請參閱長橋 App 中關於餘額通的部分獲取更多信息。</p><h2>4. 交易結算</h2><p>長橋綜合賬戶將以交易貨幣進行對應結算。</p><ul><li><strong>買入合約結算：</strong>買入合約將在合約到期日結算。</li><li><strong>賣出合約結算：</strong>賣出合約結算將在履行交貨義務後進行。</li></ul><h2>5. 在線交易記錄及對賬單</h2><p>只要該月有交易行為，月末將提供一份詳細的賬戶月結單。</p><h2>6. 轉賬匯款</h2><p>詳情請參閱 App 中出金入金指引。</p><p> </p><p><strong>關鍵要點</strong>：</p><ul><li><strong>保證金體系</strong>：<ul><li>初始保證金 (IM)：開倉最低要求</li><li>維持保證金 (MM)：持倉警戒線</li><li>平倉保證金 (FM)：強製平倉閾值</li><li>計算公式：股權資產 = 現金余額 (分類賬) + 投資組合總市值</li></ul></li><li><strong>杠桿控製</strong>：<ul><li><strong>最大購買力</strong> = 可用資金 / 初始保證金（IM）可用資金（包含融資）= 股權資產- 初始保證金要求 - 凍結資金</li><li><strong>可用資金（包含融資）</strong>= 股權資產- 初始保證金要求 - 凍結資金</li></ul></li><li><strong>風控流程</strong>：<ul><li>股權資產＜MM 時，需 3 個交易日內補足差額</li><li>股權資產＜FM 時，可能即時強平</li></ul></li><li><strong>增值服務</strong>：余額通自動投資貨幣基金，提升閑置資金收益</li></ul><p> </p><p><strong>免責聲明</strong></p><p>本文僅供參考，不構成任何投資建議。</p>
