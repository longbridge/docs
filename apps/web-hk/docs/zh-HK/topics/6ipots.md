<p>敲入界限是<strong>判斷投資者是否須承擔接貨風險的價格線</strong>，通常設定得比敲出界限低很多（如初始價的 <strong>70% / 75%</strong>）。</p><p>若掛鈎標的<strong>跌穿敲入界限</strong>，就可能觸發潛在虧損機制——最典型的是<strong>按行使價買入掛鈎標的</strong>（個股／ETF 等可交收標的），或以<strong>現金結算</strong>方式承擔本金虧損（指數類等不可交收標的）。</p><blockquote><p>敲入本身<strong>不等於即時虧損</strong>，最終是否虧損還須視乎到期價格是否低於行使價。</p></blockquote><p><strong>敲入的兩種觀察方式：</strong></p><p><strong>美式觀察（AKI）：</strong>存續期內，<strong>任一交易日的收市價</strong>低於敲入界限，即觸發敲入。</p><p><strong>歐式觀察（EKI）：僅於到期日</strong>觀察，<strong>到期日收市價</strong>低於敲入界限，方觸發敲入。</p>
