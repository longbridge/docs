<p>購買 FCN 後會出現幾種回報情況：</p><p><strong>提前敲出</strong>：任一觀察日表現最差標的價格 <strong>≥</strong> 敲出界限。</p><p><strong>回報</strong>：返還全部本金 + 已累計派發的票息，產品提前結束。</p><p><strong>產品到期結束</strong></p><p><strong>條件</strong>：產品任一觀察日未敲出，且到期時所有標的均在行使價之上<strong>或</strong>（設有敲入界限時）<strong>全程未觸發敲入</strong>。</p><p><strong>回報</strong>：返還全部本金 + 整個期限內的所有固定票息。</p><p><strong>觸發接貨</strong></p><p><strong>條件</strong>：未敲出，且到期最差標的 &lt; 行使價——無敲入界限時直接判定，設有敲入界限時還須已觸發敲入。</p><p><strong>回報</strong>：<strong>票息照收</strong>（整個期限的固定票息），但本金按<strong>行使價承接股票</strong>，承擔下跌損失。</p>
