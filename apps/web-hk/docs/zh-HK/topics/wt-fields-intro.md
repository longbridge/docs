<p>本文介紹了港股輪證的基礎知識，涵蓋窩輪、牛熊證、界內證三大類產品的命名規則、生命周期、通用行情指標及特有參數，幫助投資者理解輪證交易的核心機制與風險特征。</p><h2>1. 輪證各類型基礎信息</h2><p>港股輪證分為以下三種大類，其中，窩輪和牛熊證有方向的，界內證無方向。</p><figure class="table"><table><tbody><tr><td>輪證類型</td><td>方向</td><td>名稱示例</td><td>命名規則</td></tr><tr><td rowspan="2"><p>窩輪：</p><p>衍生權證 Warrant</p></td><td>看漲</td><td>QQZZ 年月購 A</td><td rowspan="5"><p>QQ - 相關資產</p><p>ZZ - 發行商</p><p>年 - 到期年份</p><p>月 - 到期月份。 1 月至 10 月將以中國數字（一、二…十）代表；11 月及 12 月分別以「甲」及「乙」代表</p><p> </p><p> </p><p> </p><p>購 - 認購證（購）； 認沽證（沽）； 非認購或認沽證（ ）</p><p>牛 - 牛證（牛）或是熊證（熊）</p><p>界 = 界內證</p><p> </p><p>A - 同一發行商就同一相關資產再發行同一到期年月的衍生權證，以顯示系列編號（A,B,C…）</p><p> </p><p> </p><p>* - 以人民幣買賣的衍生</p><p>權證之代表符號</p><p>窩輪 QQZZ 年月 A*</p><p>牛熊 QQZZ 月牛 A*</p></td></tr><tr><td>看沽</td><td>QQZZ 年月沽 A</td></tr><tr><td rowspan="2">牛熊證：CBBC for Callable Bull-Bear Contracts</td><td>看漲</td><td>QQZZ 年月牛 A</td></tr><tr><td>看沽</td><td>QQZZ 年月熊 A</td></tr><tr><td>界內證：Inline Warrant</td><td>區間價格</td><td>QQZZ 年月界 A</td></tr></tbody></table></figure><h2>2. 輪證生命週期</h2><p>類似普通股票，輪證也會有等待上市、正常交易、終止交易的流程。</p><h2>3. 輪證通用行情字段介紹</h2><h3>街貨量 &amp; 街貨比</h3><p>街貨量：指市場上由其他投資者持有的輪證數量。</p><p>街貨比：指市場上由其他投資者持有的輪證佔輪證總發行量的比例。</p><h3>換股價 &amp; 換股比率</h3><p>「換股比率」是指，多少單位的輪證可以換 1 股正股，兌換時對應正股的價格，稱為「換股價」。</p><h3>溢價</h3><p>指投資者以現價買入某輪證並持有至到期時，正股需要上升或下跌多少才能使這筆投資保本。溢價越小，贏的機會就越大。</p><ul><li>認購證 &amp; 牛證的溢價 ＝（最新價×換股比率＋行使價－正股價）/正股價×100％</li><li>認沽證 &amp; 熊證的溢價 ＝（最新價×換股比率－行使價＋正股價）/正股價×100％</li><li>界內<ul><li>當下限價 &lt;= 正股價格 &lt;= 上限價時，溢價 = 0.00%</li><li>當正股 &lt; 下限價時，溢價 =（下限價 - 正股價）/正股價 x 100%</li><li>當正股 &gt; 上限價時，溢價 =（正股價 - 上限價）/正股價 x 100%</li></ul></li></ul><h3>打和點</h3><p>指當投資者買入並持有輪證到期之前，正股需要漲/跌到多少價格，投資者才可以盈虧平衡。</p><ul><li>認購證 &amp; 牛證打和點 = 行權價 +（最新價 x 換股比率），即 = 行權價 + 換股價</li><li>認沽證 &amp; 熊證打和點 = 行權價 -（最新價 x 換股比率），即 = 行權價 - 換股價</li></ul><h3>槓桿比率</h3><p>槓桿比率是用來衡量投資者買入輪證的價格與正股的市價之比，槓桿比率越高，盈利時的比例或虧損的風險也越大。</p><ul><li>槓桿比率 = 正股價格 /（輪證價格 x 換股比率）</li><li>特別的，界內證的槓桿比率：槓桿比率 = 1 / 界內證價格</li></ul><h2>4. 窩輪的（認股證）特殊字段介紹</h2><h3>引申波幅 </h3><p>窩輪在結構上類似期權，引申波幅是指將窩輪價格帶入期權定價模型（一般用 BS 定價模型）中，反推得到正股的隱含波動性。</p><h3>對沖值</h3><p>對沖值也稱 Delta，公式：Delta =（輪證價格變化 * 換股比率）/ 正股。認購證對沖值由 0 至 1，認沽證對沖值由 -1 至 0，窩輪越價外，對沖值越接近 0。</p><h3>有效槓桿</h3><p>使用中，僅看輪證的槓桿比例可能並不能實際反映槓桿情況，有效槓桿是反映正股價格每變動 1%，窩輪價格的有效理論變幅，與對沖值有關。</p><p>公式：有效槓桿 = 對沖值 x 正股價格 / (輪證價格 x 換股比率)</p><h2>5. 牛熊證的特殊字段介紹</h2><h3>收回價 &amp; 距收回價</h3><p>與其他兩種輪證不同，牛熊證具有回收機制。當正股價格觸及收回價，牛熊證將立刻停止交易作廢。</p><p>距收回價衡量了與正股現價之間的百分比。公式：距收回價 =（正股最新價 - 收回價）/ 收回價×100%</p><p> </p><p><strong>關鍵要點</strong>：</p><ul><li><strong>產品類型</strong>：港股輪證分為窩輪（看漲/看跌）、牛熊證（帶強製收回機製）和界內證（區間波動）三大類。</li><li><strong>核心指標</strong>：通用字段包括街貨量、溢價、打和點和杠桿比率。</li><li><strong>特有參數</strong>：<ul><li>窩輪：引入引申波幅、對沖值和有效杠桿。</li><li>牛熊證：設有收回價，正股觸及即終止交易，需重點關註距收回價風險。</li></ul></li></ul><p> </p><p><i>本文僅供參考，不構成任何投資建議。</i></p>
