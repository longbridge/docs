<p>從 Computershare 轉出股票的流程，包括以下六個步驟：</p><p>步驟 1. 通過阿裏健康工作郵箱向 CS（AliHealthSharePlans@computershare.com.au）發郵件申請轉出股票。</p><p>步驟 2. 收到來自 CS 的郵件回復，同步轉倉步驟。（郵件示例如下，僅供參考）</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/9993c7b2d754f7241a5969fbc25baa4e"/></figure><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/603754fab7239ddf4e432680e16dac55"/></figure><p>步驟 3.  需回復確認轉出股票並支付轉股手續費（375 港幣）至 CS 郵件中提供的收款賬戶。</p><p>支付完成後需回復 CS 郵件並提供支付憑證，對方收到您的手續費後，會再次給您發郵件提供您的股票存儲券商相應信息並要求您提供轉入券商信息（轉入券商信息如下）及轉出股票數量。</p><p>轉入資料</p><figure class="table"><table><colgroup><col style="width: 32.81%"/><col style="width: 67.19%"/></colgroup><tbody><tr><td>券商名稱</td><td>Long Bridge HK Limited 長橋證券（香港）有限公司</td></tr><tr><td>參與者代號</td><td>B02195</td></tr><tr><td>賬號</td><td>您的長橋證券賬號（H 開頭）</td></tr><tr><td>賬戶名稱</td><td>LI XIAOHUA（當前用戶的賬戶拼音名）</td></tr><tr><td>聯繫人姓名</td><td>交收部</td></tr><tr><td>聯繫人 Email</td><td><a href="mailto:settlement@longbridge.hk">settlement@longbridge.hk</a></td></tr><tr><td>聯繫電話</td><td>(+852) 35858944 / (+852) 35858915</td></tr></tbody></table></figure><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/f295b3275a7400ea576f8ebdbd446566"/></figure><p>步驟 4. 確認後 CS 會回復一封郵件確認您的轉出券商信息，並提供股票存儲券商處的相應聯系人、聯系方式以及預計交割日期等。（郵件示例如下，僅供參考）</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/6700df59bca49b1c8492b8483d37f844"/></figure><p>步驟 5. 您在完成以上步驟後，按照 CS 郵件中提供的信息在長橋 App 提交股票轉入申請。</p><p>步驟 6.  完成操作後，券商之間互相聯系確認轉倉事宜，請耐心等待；一旦對方券商轉出股票，將在 1~2 個工作日存入您的證券賬戶。</p><h3><strong>溫馨提示</strong></h3><ol><li>股票在不同券商間的轉移僅限於同名賬戶的轉移。</li><li>轉入股票費用：長橋證券不收取費用，轉出券商收取費用。</li><li>轉入股票時間：取決於對方券商，一旦對方券商轉出股票，長橋證券將在 1-2 個工作日存入客戶賬戶。</li></ol><p> </p><p><strong>免責聲明</strong></p><p><i>本文僅作參考，所需確認信息請以實際顯示為準，上方指引中信息僅作為操作示例。</i></p><p><i>本文不構成任何投資建議。</i></p>
