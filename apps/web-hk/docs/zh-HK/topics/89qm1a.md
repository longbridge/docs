<p style="margin-left: 0px"><strong>導語：</strong><br/>Longbridge 已作為官方連接器（MCP）上線 Claude。連接後，你可以在 Claude 裡直接用對話調用 140+ 項行情與研究能力，US、HK 即時行情對 Longbridge 用戶免費開放。</p><blockquote><p style="margin-left: 0px">適用平台：Claude 網頁版 / 桌面 App / Claude Code ｜ 費用：行情免費開放 ｜ 耗時：約 1 分鐘</p></blockquote><p style="margin-left: 0px"><strong>一句話總結：</strong> 在 Claude 的「Connectors（連接器）」裡搜尋 Longbridge，一鍵連接你的 Longbridge 帳號，之後直接用中文提問就能查行情、看財報、分析持倉。</p><h2 style="margin-left: 0px">一、Longbridge AI 是什麼</h2><p style="margin-left: 0px">Longbridge AI 是 Longbridge 面向 AI 場景推出的官方連接器，基於 MCP（Model Context Protocol）協議。它把 Longbridge 的行情、財務、研究、帳戶能力打包成 Claude 可以直接調用的工具——你不用再切換 App、複製貼上資料，直接對 Claude 說人話即可。</p><p style="margin-left: 0px">繼 ChatGPT 之後，Claude 現已支援直接連接 Longbridge 帳號。</p><h2 style="margin-left: 0px">二、連接前的準備</h2><p style="margin-left: 0px">你只需要兩樣東西：</p><ul><li><strong>Longbridge 帳號</strong>：已註冊的 Longbridge 帳號，用於授權連接（查詢持倉、訂單需授權後可用）。</li><li><strong>Claude 客戶端</strong>：Claude 網頁版、桌面 App 或 Claude Code 任一皆可，登入你的 Claude 帳號。</li></ul><h2 style="margin-left: 0px">三、連接步驟</h2><p style="margin-left: 0px"><strong>第 1 步 打開連接器面板</strong><br/>在 Claude 網頁版 / 桌面 App 左側點擊 Customize → Connectors 面板。Claude Code 走同樣的路徑。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2026/7e17a7d1af653480bba2530bbbf0d13d"/></figure><p style="margin-left: 0px"><strong>第 2 步 搜尋 Longbridge</strong><br/>在連接器目錄裡搜尋「Longbridge」，找到官方連接器 Longbridge MCP。也可直接前往官方目錄：<a href="https://claude.ai/directory/longbridge">https://claude.ai/directory/longbridge</a></p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2026/363cfcf015a4227ca2221eb7f64b51af"/></figure><p style="margin-left: 0px"><strong>第 3 步 點擊連接並授權</strong><br/>點擊 Connect，依提示登入並授權你的 Longbridge 帳號。授權成功後，140+ 工具即刻可用。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2026/37829dd3bc8f477e611ba245a59e478c"/></figure><p style="margin-left: 0px"><strong>第 4 步 開始對話</strong><br/>回到對話框，用中文直接提問即可，例如「幫我看下特斯拉最新財報」。Claude 會自動調用 Longbridge 工具取數並分析。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2026/e59b59cbfb6187ca5c410b36ddb8e6e7"/></figure><h2 style="margin-left: 0px">四、連接後你能做什麼</h2><p style="margin-left: 0px">涵蓋 140+ 項能力，主要分四類：</p><ul><li><strong>行情</strong>：即時報價、完整歷史 K 線、盤口、資金流。US / HK 即時行情免費開放。</li><li><strong>基本面</strong>：財報三表、派息紀錄、估值倍數、業務構成。</li><li><strong>研究</strong>：分析師一致預期與目標價、股東變動、機構持倉、內部人交易。</li><li><strong>帳戶</strong>：授權後可查詢你的即時持倉與訂單，做個人化分析。</li></ul><h2 style="margin-left: 0px">五、試試這樣問</h2><p style="margin-left: 0px">連接成功後，直接把下面這些丟給 Claude：</p><ul><li><strong>財報體檢</strong>：幫我對輝達最近一期財報做一次全面體檢，重點看增長和盈利品質。</li><li><strong>財報季對比</strong>：把蘋果這一季和去年同期、上一季對比一下，有哪些變化？</li><li><strong>估值評估</strong>：騰訊大跌之後現在的估值貴不貴？和歷史區間比呢？</li><li><strong>機構參考</strong>：分析師對特斯拉的一致預期和目標價是多少？</li><li><strong>持倉分析</strong>：看看我的持倉，幫我做個結構和風險分析。</li></ul><h2 style="margin-left: 0px">六、常見問題</h2><p style="margin-left: 0px"><strong>Q：行情要收費嗎？</strong><br/>A：US、HK 即時行情在 AI 場景下對 Longbridge 用戶免費開放，無需額外購買行情權限。</p><p style="margin-left: 0px"><strong>Q：在 Claude Code 裡也能用嗎？</strong><br/>A：可以。Claude Code 走和網頁版 / 桌面 App 相同的連接器路徑，搜尋並連接 Longbridge 即可。</p><p style="margin-left: 0px"><strong>Q：連接會不會洩露我的帳戶資訊？</strong><br/>A：連接採用官方授權機制，持倉、訂單等帳戶資料僅在你授權後可查詢。你可以隨時在 Connectors 面板中斷連接。</p><p style="margin-left: 0px"><strong>Q：找不到 Longbridge 連接器怎麼辦？</strong><br/>A：請確認 Claude 客戶端為最新版本；也可以直接前往官方連接器目錄<a href="https://claude.ai/directory/longbridge">https://claude.ai/directory/longbridge</a> 進行連接。</p>
