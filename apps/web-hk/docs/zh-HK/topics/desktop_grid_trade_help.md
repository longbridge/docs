<p>網格交易是一種基於股價波動的場景下，設定好策略參數並由系統根據參數執行低買高賣從而賺取波段差價的交易策略。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/ec364c9204b7ecf8dcf61fababa4ca4e"/></figure><p>投資者事先將資產分成多份，設定好基準價格以及基於基準價格上漲下跌的價差繪製對應網格，當股價下跌觸發網格時，按照設定的價格和數量買入一份，相反當股價上漲觸發網格時，賣出一份，通過反復買入賣出的操作，賺取差價。</p><h3>如何提交網格策略？</h3><p>步驟 1. 在新開標簽頁 &gt; 自適應標簽，選擇網格交易。</p><p>步驟 2. 按界面提示輸入價格和數量參數後提交策略。</p><p>步驟 3. 提交成功之後，可在右側查看網格訂單以及訂單的觸發歷史信息。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/9ce80589c5658fa4d5b6694ecc085886"/></figure><p>注：當出現策略不適用於當前行情趨勢，或者其他原因需要暫停監控的話，可點擊策略單，選擇暫停操作，或直接撤銷。若需要調整策略參數，可點擊修改進行改單操作。</p><h3>策略參數如何設定？</h3><p><strong>基準價格：</strong>網格策略的初始計算價格，系統將以基準價格為起點，結合用戶設定的觸發條件，計算出基準價格上下的網格，並即時監控股票市價是否有觸及網格。當市場價格向上或向下觸發到設定網格后，觸發價格將成為新的基準價格，并依據觸發條件計算新的網格。</p><p><strong>最大價格、最小價格：</strong>整個網格策略運行的有效價格區間，作為風險控制使用，如果運行過程中觸發價格高過最大價格或低於最小價格，則認為超出網格策略預期的有效價格區間。</p><p><strong>超過價格區間：</strong>可選擇不做任何委託或直接按最新價清倉該股票所有倉位。</p><p><strong>觸發條件：</strong>决定網格大小的參數，可按照價差或百分比來設定上下網格區間，並分開設定上漲或下跌觸發網格後，委託的價格。 例如基準價格為 100，按照價差上漲 1.00 元以賣一價委託，下跌 1.5 元以買一價委託，若股價漲到 101 元，觸發上方網格，按照賣一價和每筆委託數量委託賣出訂單； 若股價下跌至 98.5 元，觸發下方網格，按照買一價和每筆委託數量委託買入訂單。</p><p>市價（市價單）：當網格觸發時會向市場下達一個市價單，實際的成交價格由當時的市場行情決定。</p><p>市價（限價單）：當網格觸發時會向市場下達一個限價單，限價為觸發時的市價價格，實際的成交價格會優於這個限價價格，也可能不會立即成交。</p><p>觸發價（限價單）：當網格觸發時會向市場下達一個限價單，限價為觸發價，實際的成交價格會優於這個限價價格，也可能不會立即成交。</p><p><strong>每筆委託數量：</strong>當股價波動觸發到設定網格時，下單的數量。</p><p><strong>有效期：</strong>支持長期單，可選項包括當日有效、撤單前有效、自定義有效期。</p><p><strong>時段：</strong></p><ul><li>僅盤中：網格交易僅在盤中時段執行。</li><li>盤中 + 盤前盤後：網格交易可在盤前，盤中，盤偶時段執行。因盤前盤後時段僅支持限價單下單，觸發條件不支持選擇市價（市價單）。</li></ul><p><strong>倍數委託：</strong>如果打開倍數委託，當股價出現跳空高開或低開超過一個網格的情况下，按照覆蓋的網格數量委託對應倍數的每筆委託數量。</p><p><strong>持倉區間：</strong>如果打開持倉區間控制，可設定最大最小持倉，當觸發網格後下單則檢查是否會超過持倉區間，如果超過則不進行委託。</p><p><strong>支持賣空：</strong>如果打開支持賣空，持倉為零可自動做空。如果關閉支持賣空，持倉為零不執行賣出。</p><blockquote><p>注：網格交易不支持美股夜盤及港股競價時段交易。</p></blockquote><p> </p><h3>關鍵要點：</h3><p>網格交易在設定好基準價格以及基於基準價格繪製對應網格，通過反復買入賣出的操作，賺取差價。設置策略參數包括基準價格、最大最小價格、超過價格區間、觸發條件、每筆委托數量、有效期、時段、倍數委托、持倉區間、支持賣空。</p><p> </p><h3>常見問題解答</h3><p><strong>Q1: 為什麽行情滿足的情況下，我的網格訂單沒有觸發？</strong></p><p>可能是設置的網格最大持倉，最小持倉，價格區間，現有持倉不足，購買力不足等原因影響，建議檢查網格訂單的參數設置，確保它們符合交易條件。</p><p><strong>Q2: 為什麽行情不滿足的情況下，我的網格訂單觸發了？</strong></p><p>網格訂單的觸發是基於實時逐筆成交，而行情圖顯示的是按時間加權後的結果，這可能導致顯示的行情與實際成交情況不符。</p><p><strong>Q3: 為什麽設置網格需超過 5 個報價檔位且超過基準價的 0.5%？</strong></p><p>系統為了保護用戶，設置了參數限製，要求網格訂單的設置參數與基準價格有一定的距離。如果設置的觸發條件間隔過小，可能會導致收益不足以覆蓋交易手續費。</p><p> </p><p><i>本文僅供參考，不構成任何投資建議。</i></p>
