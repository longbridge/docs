<p>本文將快速解答關於期權的常見疑問。</p><h4>1.賣出看漲期權 (Short Call) 後若被行權，可以用正股支付嗎？需要單獨開通該功能嗎？</h4><p>目前默認是使用正股支付，無需開通該功能。</p><h4>2.為什麼有些美股沒有期權入口？</h4><p>長橋當前支持大部份流通性高的美股期權，沒有覆蓋的期權其流通性風險相對較高。我們會不時評估產品的風險，計劃陸續增添可交易的期權產品數量。</p><h4>3.賣出看漲期權 (Short Call) 後正股會自動被備兌 (Covered Call) 嗎？</h4><p>一般情況下，賣出看漲期權 (Short Call) 不會鎖定對應標的持倉，您的股票依然可以賣出。但在期權到期日當天，期權達到價外 2%-5%* 之內正股則會備兌。備兌後正股會被凍結，該時候正股將不能賣出。</p><p>注：視乎情況，若巿況波動期權可能會於相對較遠價外進行備兌。</p><h4>4.哪些情況會影響期權保證金的變動？</h4><p>除了期權本身的價格波動、標的股票的價格波動會影響保證金要求外，還會受到期權到期日的影響。</p><h4>5.期權到期時沒有操作或者賣不出去，這種情況是自動行權嗎？</h4><p>視乎情況。末日期權若然有內在價值，一般情況下都會自動行權。但如果行權保證金不足，我們可能會在到期日按情況執行強平。</p><blockquote><p>舉例</p><p>如果是買入看跌期權 (Long Put) 或賣出看漲期權 (Short Call) 的話，而相關正股為不支持沽空（融券）時，您需要有足夠正股支持行權。如沒足夠數量的正股，期權可能會被強平；如果相關正股支持沽空（融券）的話，價內期權在保證金足夠的情況下，而到期時客戶沒有平倉該期權，將會被自動行權。但如果賬戶內沒足夠資金，期權可能會被強平。</p><p>如果是買入看漲期權 (Long Call) 或賣出看跌期權 (Short Put) 的話，價內期權在保證金足夠的情況下，而到期時客戶沒有平倉該期權，將可能會被行權。但如果賬戶內沒足夠資金，期權可能會被強平。</p></blockquote><p>注：沒有行權而且沒有平倉的期權，到期時將自動作廢且失去所有價值。</p><h4>6.如果賬戶沒有足夠資金行權是否會行權失敗？失敗還會扣行權的費用嗎？</h4><p>一般情況下，以防期權到價時行權失敗，我們會事先提高期權的保證金要求。但是，如在保證金不足的情況下，我們有可能會把保證金不足的期權強制平倉。</p><h4>7.長橋美股是否支持賣出看漲 (Short Call) 期權備兌策略保證金減免？ </h4><p>若是您持有足夠正股同時進行賣出看漲期權 (Short Call) 交易，可以減少或抵消賣出看漲期權 (Short Call) 的開倉保證金要求。</p><h4>8.我如何得知自己期權開倉保證金水平不足？我有必要自行計算期權保證金嗎？</h4><p>期權保證金會受股票價格、持倉數量、波幅、流通性風險等眾多因素影響，且算式複雜，一般客人都不願意自行計算。開倉時保證金不足的話您會得到訂單金額超出最大購買力的提示，您可以在訂單詳情查看。</p><h4>9.價內期權會自動行權嗎？觸發點是多少？</h4><p>只要達到價內 USD0.01，則將有可能會被行權。按具體情況而定。但值得留意的是，賣出期權 (Short options) 時，即使價外（特別是當正股停牌時）仍有機會會被行權。</p><h4>10.我作為賣出方被行權，我可以持有空頭股票嗎？</h4><p>如果您賣出看漲 (Short Call) 期權，而相關正股支持沽空（融券），賬戶沒有持有足夠對應的正股，並且進入價內時，將會自動行權，如您的賬戶沒有足夠保證金，一般情況下，期權會在到期日被強平。</p><h4>11.所有的期權交易類型都需要保證金嗎？</h4><p>買入看漲 (Long Call) 及買入看跌 (Long Put) 需要付出期權金；賣出看漲 (Short Call) 及 賣出看跌 (Short Put) 則需要預留保證金。</p><h4>12.期權交易是否只做買入的權利倉，就不會導致負債？</h4><p>價內期權在沒有足夠資金下行權將可能會導致負債；如果是買入看跌 (Long Put) 及賣出看漲 (Short Call) 同時相關正股為不支持沽空（融券）的話，到期日會被強平，所以正常情況下不會出現負股票狀態。</p><h4>13.是否可以提前行權？</h4><p>長橋目前不支持主動行權，只能在到期日自動行權；沽出期權有可能會被提前行使義務。</p><blockquote><p>買入看漲期權/賣出看跌期權： 被行權時買入正股，買入正股數目按照期權行使價買入，股數按期權行權張數 *100，同時期權會被收回。</p><p>買入看跌期權/賣出看漲期權：被行權時賣出正股，賣出正股數目按照期權行使價賣出，股數按期權行權張數 *100，同時期權會被收回。 若客戶未持有對應足額正股時，有可能會變成沽空處理。</p></blockquote><h4>14.若期權到期被行權，產生負股票持倉怎麼辦？</h4><p>買入看跌 (Long Put) 及賣出看漲 (Short Call) 同時相關正股為不支持沽空（融券）的話，正常情況下，您的賬戶不會出現負股票狀態。但相關正股支持沽空（融券）的話，價內期權會自動行權，將產生負股票持倉。您可以選擇保持沽空（融券）狀態或平倉。</p><p>如果您的長橋綜合賬戶尚未開通融券功能，行權後的負持倉可能會在第二個交易日被強平。</p><h4>15.期權之間的期權金/保證金，可以互相抵消嗎？ </h4><p>長橋目前支持在持有正股股票多倉的情況下賣出看漲期權（Short Call）而形成 Covered Call，或者持有正股股票空倉的情況下，賣出看跌期權（Short Put）而形成 Covered Put，這兩種場景下，能夠減少或抵消 賣出看漲期權（Short Call）和 賣出看跌期權（Short Put）的保證金要求。</p><h4>16.我持有免佣卡，期權交易是否可以使用？</h4><p>很抱歉，期權不支持使用免佣卡。</p><h4>17.賣出看漲期權 (Short Call) 備兌策略減免保證金後爲何仍有凍結保證金？</h4><p>在持有正股的情況下賣出看漲期權（Short Call），長橋證券不會額外計算保證金，但會凍結該空頭看漲期權市值，使該筆期權金不能用於提現、交易或槓桿使用，確保賬戶留有足夠資金可以平倉。</p><h4>18.通過組合保證金建立的持倉頭寸，在加倉或減倉時會有什麼影響？</h4><p>若對正股進行加倉，不會對已經形成的 Covered Call / Covered Put 形成影響，相反因增加了正股持倉，可能會提升賣空看漲期權或看跌期權的可賣出數量；若對正股進行減倉，因有可能會在正股賣出後，導致已形成組合的正股數量不足，會產生裸賣空期權，此時會重新計算帳戶保證金要求。</p><h4>19.什麼是期權 Penny Interval Program？</h4><p>Penny Interval Program href="https://www.cboe.com/us/options/market_statistics/penny_tick_type/?mkt=cone">Penny Tick Type Reports (cboe.com)</a></p><h4>20.為什麼期權賣出價低于（或買入價高于）逐筆但沒有成交？</h4><p style="margin-left: 0px">在交易美股期權時，有時會看買賣盤中有以更差價格成交的記錄，自己的訂單價格更優卻沒成交。可能是由于以下原因：</p><p style="margin-left: 0px">(1). 期權市場流動性正常，但由於美股特殊的報價規則（美股買賣盤 BBO / NBBO 報價規則），在買賣盤上看到的買一賣一是不同交易所的最高買入價 bid 和最低賣出價 offer 的報價，有部分訂單是有可能會被路由到其他交易所進行撮合交易的。</p><p style="margin-left: 0px">另外，當交易不活躍時，不同交易所的報價有可能會存在較大的差異，但未及時同步，可能導致期權訂單不能成交。</p><p style="margin-left: 0px">(2). 由于期權存在組合訂單，所以進行期權交易時，如果提交了期權單邊的買/賣訂單，這樣的訂單就不一定能夠成交。</p><p style="margin-left: 0px">例如，有些券商允許客戶通過同時掛出一個 Long Call 和 Short Call 的訂單來進行期權組合訂單（Spread）的交易。只有當 Long 和 Short 的價格都符合買賣價時，該訂單組合中的兩個訂單會同時成交。</p><p style="margin-left: 0px">以一個具體的例子來看，BABA 的某只期權，當前的買一價為 $3.00，並且這個買單是交易所撮合的某個組合訂單的一部分。這時提交一個 $2.80 的賣單，不一定能夠確保成交。</p><p style="margin-left: 0px">以上所描述的是美股期權市場的正常現象，期權訂單已經提交至上游券商，是否能夠成交取決於交易所是否撮合。</p><p style="margin-left: 0px"> </p><p style="margin-left: 0px"><i>本文僅供參考，不構成任何投資建議。</i></p>
