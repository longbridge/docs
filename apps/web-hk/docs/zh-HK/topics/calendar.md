Spread）和賣出跨期看跌期權（Short Put Calendar Spread）這四種策略的詳細內容，包括策略概述、特點、構成、盈利來源及案例解析，從而更好地運用這些策略進行投資。</p><h3>1. 買入跨期看漲期權 Long Call Calendar Spread</h3><ul><li>策略概述</li></ul><p>買入跨期看漲期權（Long Call Calendar
