<p><strong>現金結算（Cash Settlement）：</strong>雙方只按差額<strong>收付現金</strong>，不交付任何證券。適用於<strong>不可交收的標的</strong>（如指數、匯率），例如掛鈎 SPX / HSI / CSI1000 的產品。</p><p><strong>實物交收（Physical Delivery）：</strong>直接把掛鈎<strong>標的交付予投資者</strong>（即「接貨」），投資者按約定價格（行使價）買入該證券。適用於<strong>掛鈎股票</strong>的產品（如掛鈎個股／ETF）。</p>
