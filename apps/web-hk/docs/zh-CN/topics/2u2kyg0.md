<p>以下是关于追缴保证金的详细介绍和案例。</p><p>当股权资产低于维持的水平时，本公司会发出追缴保证金通知。 客户必须在收到通知起 3 个交易日内（包括收到通知当日）清缴追缴保证金差额。<strong>追缴保证金将会高于维持保证金和股权资产的差额。</strong></p><p style="margin-left: 0px"><strong>注意：</strong> 在以下高风险情况下，为控制账户整体风险，本公司可能无法等待完整 3 个交易日，而会立即采取强制平仓等措施：</p><ul><li><strong>持有末日期权</strong>：由于末日期权价值可能在短时间内剧烈波动或归零，导致账户资产迅速恶化。</li><li><strong>市场极端波动</strong>：当标的资产价格出现急剧波动，致使账户资产快速跌破强平线。</li><li><strong>其他流动性风险</strong>：本公司判断账户存在无法在 3 日内覆盖亏损的较高风险时。</li></ul><p style="margin-left: 0px"> </p><h4>示例：追缴保证金案例</h4><blockquote><p>客户存入$10,000 现金及价值$5,000 的 A 股票（IM：30%， MM：25%），并购买了价值$ 25,000 的 B 股票（IM：50%， MM：45%）。 假设 B 股票的市值跌至$19,500。</p></blockquote><p>客户购入股票后，B 股票的市值下跌后，客户持仓为下</p><figure class="table"><table><colgroup><col style="width: 18.32%"/><col style="width: 81.68%"/></colgroup><tbody><tr><th>现金结欠</th><td>HKD 15,000</td></tr><tr><th>持仓初始保证金</th><td>HKD 11,250 (HKD 5,000 X 30% + HKD 19,500 X 50%)</td></tr><tr><th>持仓维持保证金</th><td>HKD 10,025 (HKD 5,000 X 25% + HKD 19,500 X 45%)</td></tr><tr><th>股权资产</th><td>HKD 9,500</td></tr><tr><th>追缴保证金 *</th><td>HKD 1,750</td></tr></tbody></table></figure><p>客户需在指定日期或之前使其账户的股权资产达至保证金要求。</p><p>如客户选择卖出证券，所需卖出的市值则不多于初始保证金和股权资产的差额/初始保证金系数 (IM Ratio)</p><p><strong>当股权资产低于强平保证金时，必需立即清缴追缴保证金差额， 否则持仓可能被即时强平。</strong></p><p><strong>注：实际追缴金额可能较高，视乎股票性质和公司政策而定。</strong></p><p> </p><p><strong>关键要点</strong>：</p><ul><li>触发条件：股权资产价值低于维持保证金水平。</li><li>追缴金额：追缴金额通常高于维持保证金与股权资产的差额。</li><li>处理时限：收到通知后需在 3 个交易日内补足资金或减仓。</li></ul><p> </p><p><strong>免责声明</strong></p><p><i>本文仅供参考，不构成任何投资建议。</i></p>
