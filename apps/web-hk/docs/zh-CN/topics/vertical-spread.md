<p>Vertical spread 垂直策略包含多种具体策略，适用于不同市场预期，帮助投资者在控制风险的同时实现收益目标。通过本文，您将了解到牛市看涨期权价差（Bull Call Spread）、牛市看跌期权价差（Bull Put Spread）、熊市看涨期权价差（Bear Call Spread）和熊市看跌期权价差（Bear Put Spread）这四种策略的详细内容，包括策略概述、特点、构成、盈利来源及案例解析，从而更好地运用这些中高级期权策略进行投资。</p><h3>1. Bull Call Spread 牛市看涨期权价差</h3><ul><li>策略概述</li></ul><p>在预期正股股价将上涨但涨幅有限，或已买入看涨期权（Call）想降低成本及对冲股价下跌风险时，使用的一种中高级期权策略。通过同时买入一个低行权价的看涨期权（Call A）和卖出一个高行权价的看涨期权（Call B）来构建，两者行权价不同，但标的股票、到期日、方向类型相同。</p><ul><li>策略特点</li></ul><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/95ee94a6c3f6b9c8b261c435db7a2ad7"/></figure><ul><li>策略构成</li></ul><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/2c79019d9a7e3cbe242fcfc81b6eb890"/></figure><ul><li>盈利来源<ul><li>「买入 Call A」实现看涨预期，赚取正股上涨收益；</li><li>「卖出 Call B」降低「买入 Call A」的成本</li></ul></li><li>案例解析</li></ul><p>以虚构的上市公司 TECH 为例，TECH 现价 $100，你认为 TECH 公司的股价在未来一段时间内将呈现温和上涨的态势，但涨幅不会过大。</p><p>决定构建牛市看涨期权价差（Bull Call Spread）策略。</p><p>买入一个低行权价的看涨期权（Call A），行权价为$100，权利金为$4；同时卖出一个高行权价的看涨期权（Call B），行权价为$110，权利金为$1.5。假设合约乘数为 100，你分别买入和卖出了 1 张期权合约。</p><figure class="table"><table><colgroup><col style="width: 33.33%"/><col style="width: 33.33%"/><col style="width: 33.34%"/></colgroup><tbody><tr><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/ba3d88639cbadb323c27a737e6c74120"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://assets-canary.lbkrs.com/uploads/1_24651_magi9bjf1ge5x1jojm5_.jpeg"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/618bcfcea75ff9a75bb49b04e2d34d3b"/></figure></td></tr></tbody></table></figure><h3> </h3><h3>2. Bull Put Spread 牛市看跌期权价差</h3><ul><li>策略概述</li></ul><p>在预期正股股价将上涨但涨幅有限，或已买入看跌期权（Put）想降低成本及对冲股价上涨风险时，使用的一种中高级期权策略。通过同时买入一个低行权价的看跌期权（Put A）和卖出一个高行权价的看跌期权（Put B）来构建，两者行权价不同，但标的股票、到期日、方向类型相同。</p><ul><li>策略特点</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/23476195836d6ed94fad7911490be2b0"/></figure><ul><li>策略构成</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/6b3e4d52f66efb5159a70f35e601193c"/></figure><ul><li>盈利来源<ul><li>「卖出 Put B」收取权利金</li><li>「买入 Put A」限制潜在损失，整体在股价上涨时获利</li></ul></li><li>案例解析</li></ul><p>以虚构的上市公司 TECH 为例，你认为 TECH 公司的股价在未来一段时间内将呈现温和上涨的态势，但涨幅不会过大。</p><p>基于这一判断，TECH 现价 $100，你决定构建牛市看跌期权价差（Bull Put Spread）策略。</p><p>买入一个低行权价的看跌期权（Put A），行权价为 $100，权利金为 $3；同时卖出一个高行权价的看跌期权（Put B），行权价为 $110，权利金为 $5。合约乘数为 100，你分别买入和卖出了 1 张期权合约。</p><figure class="table"><table><colgroup><col style="width: 33.33%"/><col style="width: 33.33%"/><col style="width: 33.34%"/></colgroup><tbody><tr><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/7d6b9367e47fc74bbdbe2ef7624ee743"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/4d3daaa5807e100fae41669cf1cef409"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/d893e8c06cb30eb0bfcdf88ec63dd270"/></figure></td></tr></tbody></table></figure><p> </p><h3>3. Bear Call Spread 熊市看涨期权价差</h3><ul><li>策略概述</li></ul><p>在预期正股股价将下跌但跌幅有限，或已卖出看涨期权（Call）想降低成本及对冲股价上涨风险时，使用的一种中高级期权策略。通过同时卖出一个低行权价的看涨期权（Call A）和买入一个高行权价的看涨期权（Call B）来构建，两者行权价不同，但标的股票、到期日、方向类型相同。</p><ul><li>策略特点</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/bdec432f01acc5d30005444a025a8946"/></figure><ul><li>策略构成</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/cff503b98f46696cb445afee19994259"/></figure><ul><li>盈利来源<ul><li>「卖出 Call A」收取权利金</li><li>「买入 Call B」限制潜在损失，整体在股价下跌时获利。</li></ul></li><li>案例解析</li></ul><p>以虚构的上市公司 TECH 为例，TECH 现价 $190，你认为 TECH 公司的股价在未来一段时间内将呈现温和下跌的态势，但不会跌幅过大。</p><p>基于这一判断，你决定构建熊市看涨期权价差（Bear Call Spread）策略。</p><p>卖出一个低行权价的看涨期权（Call A），行权价为 $190，权利金为 $4；同时买入一个高行权价的看涨期权（Call B），行权价为 $200，权利金为 $2。合约乘数为 100，你分别卖出了 1 张 Call A 合约，买入了 1 张 Call B 合约。</p><figure class="table"><table><colgroup><col style="width: 33.33%"/><col style="width: 33.33%"/><col style="width: 33.34%"/></colgroup><tbody><tr><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/56e9c799c18a00d0a86801ea7e1b68cb"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/83cdac8f8637aeb8d0922e8e11e493da"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/51d6372779385f9c469c7f9f085b5ead"/></figure></td></tr></tbody></table></figure><h3> </h3><h3>4. Bear Put Spread 熊市看跌期权价差</h3><ul><li>策略概述</li></ul><p>在预期正股股价将下跌但跌幅有限，或已买入看跌期权（Put）想降低成本及对冲股价上涨风险时，使用的一种中高级期权策略。通过同时卖出一个低行权价的看跌期权（Put A）和买入一个高行权价的看跌期权（Put B）来构建，两者行权价不同，但标的股票、到期日、方向类型相同。</p><ul><li>策略特点</li></ul><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/5dc374c9f7a01baa6584f72931e08faf"/></figure><ul><li>策略构成</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/41057521ceeeb39dd62ae859a2937562"/></figure><ul><li>盈利来源<ul><li>「买入 Put B」在股价下跌时提供保护并赚取收益</li><li>「卖出 Put A」收取权利金，降低「买入 Put B」的成本</li></ul></li><li>案例解析</li></ul><p>以虚构的上市公司 TECH 为例，TECH 现价 $80，你认为 TECH 公司的股价在未来一段时间内将呈现温和下跌的态势。基于这一判断，你决定构建熊市看跌期权价差（Bear Put Spread）策略。</p><p>卖出一个低行权价的看跌期权（Put A），行权价为$80，权利金为$3；同时买入一个高行权价的看跌期权（Put B），行权价为$90，权利金为$6。假设合约乘数为 100，你分别卖出了 1 张 Put A 合约，买入了 1 张 Put B 合约。</p><figure class="table"><table><colgroup><col style="width: 33.33%"/><col style="width: 33.33%"/><col style="width: 33.34%"/></colgroup><tbody><tr><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/3779cbcac799678e6182c03126d2a005"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/641b47b6f26079a937aee81da638a0cc"/></figure></td><td colspan="1" rowspan="1"><figure class="image"><img src="https://pub-canary.lbkrs.com/uploads/2025/1819ac7b65e037dfbecbfbf14d2ce578"/></figure></td></tr></tbody></table></figure><h3><strong>关键要点</strong></h3><ul><li>策略适用场景：明确不同垂直策略在不同市场预期下的应用，如牛市看涨、牛市看跌、熊市看涨、熊市看跌等情况。</li><li>策略构建：掌握每种策略通过买卖不同行权价期权构建组合的方式。</li><li>盈利与风险：理解各策略的盈利来源以及风险特征，包括最大收益、最大损失和盈亏平衡点的计算。</li><li>案例应用：通过实际案例分析，学会在不同市场情况下运用相应策略，并计算潜在盈亏。</li></ul><p> </p><p><i>本文内容仅供参考，不构成任何投资建议。</i></p>
