<p><strong>现金结算 (Cash Settlement):</strong> 双方只按差额<strong>收付现金</strong>，不交付任何证券。适用于<strong>不可交割的标的</strong>(如指数、汇率)，例如挂钩 SPX / HSI / CSI1000 的产品。</p><p><strong>实物交割 (Physical Delivery):</strong> 直接把挂钩<strong>标的交付给投资者</strong>(即&#34;接票&#34;), 投资者按约定价格（执行价）买入该证券。适用于<strong>挂钩股票</strong>的产品 (如挂钩个股/ETF)。</p>
