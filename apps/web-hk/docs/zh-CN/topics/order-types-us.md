<p>本文详细介绍了几种高级订单类型的核心规则、触发逻辑及适用场景，用于满足不同行情下的精准交易需求。</p><h2>1. 限价单</h2><p><strong>限价单（Limit Order</strong>）需要指定成交价格，只有达到指定价格或更好价格时才会执⾏。以更好的价格成交是指，买⼊时按比限价更低的价格成交，卖出时以比限价更高的价格成交。</p><p><strong>可成交时段</strong>：4:00 AM - 20:00 PM（美东时间）</p><p><strong>支持订单有效期</strong>：当日有效 / 撤销前有效 / 特定日期前有效</p><h2>2. 市价单</h2><p><strong>市价单（Market Order)</strong> 不需要指定价格，只需要指定下单数量。订单会按照高出当时市价的价格提交以尽量保证订单能够完全按市价成交。</p><p><strong>可成交时段：</strong>9:30 AM - 16:00 PM（美东时间）</p><p><strong>支持订单有效期：</strong>当日有效</p><blockquote><p>因盘前盘后市场流通性有限，价格波动可能较大，因此市价单只会在正常交易时间段开盘后发出。</p></blockquote><h2>3. 收盘市价单</h2><p><strong>收盘市价单（Market-On-Close）</strong>不需要指定价格，只需要指定下单数量。订单会在盘中收盘前 5 分钟下达，以接近收盘价的价格成交。</p><p><strong>可成交时段：</strong>9:30 AM - 16:00 PM（美东时间）</p><p><strong>支持订单有效期：</strong>当日有效</p><h2>4. 到价买入</h2><p><strong>到价买入（Buy if Touched）</strong>需要设定触发价格以及当市价达到触发价格后，系统需要提交买入订单的价格（市价/限价）、数量等参数。</p><figure class="image image_resized" style="width: 40.32%"><img src="https://pub.pbkrs.com/uploads/2025/0df968749a4b87d620adcb48b3cc91b1"/></figure><p><strong>触发条件</strong>： 监控行情价格达到下方设置的条件后触发&#34;委托单&#34;。</p><p><strong>市价到达</strong>： 这个价格不能等于当前价格，若设置的价格&gt; 当前最新价，代表 最新价一旦涨过设置价格就会触发。若设置的价格&lt;当前最新价，代表 最新价一旦跌过设置价格就会触发。</p><p><strong>委托单</strong>：实际要报送的订单。</p><p><strong>委托类型</strong>： 限价：限价单 , 市价：市价单（不需要输入价格）。</p><p><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效。<br/><br/><strong>示例：</strong></p><ul><li>例 1： 当前最新价 191，设置 市价达到 190.07，代表当最新价≤190.07 时刻，会进行一笔买入的委托单。</li><li>例 2： 当前最新价 191，设置 市价达到 191.07，代表当最新价≥191.07 时刻，会进行一笔买入的委托单。</li></ul><blockquote><p>到价买入可用于对空头持仓的止盈或止损。<br/> </p></blockquote><h2>5. 到价卖出</h2><p><strong>到价卖出（Sell if Touched）</strong>需要设定触发价格以及当市价达到触发价格后，系统需要提交卖出订单的价格（市价/限价）、数量等参数。</p><figure class="image image_resized" style="width: 55.53%"><img src="https://pub.pbkrs.com/uploads/2025/1972e9a2eb58503c4fff428bb6bf4805"/></figure><p><strong>触发条件</strong>： 监控行情价格达到下方设置的条件后触发&#34;委托单&#34;。</p><p><strong>市价到达</strong>： 这个价格不能等于当前价格，若设置的价格&gt; 当前最新价，代表 最新价一旦涨过设置价格就会触发。若设置的价格&lt;当前最新价，代表 最新价一旦跌过设置价格就会触发。</p><p><strong>委托单</strong>：实际要报送的订单。</p><p><strong>委托类型</strong>：  限价：限价单  , 市价：市价单（不需要输入价格）。</p><p><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效。<br/><br/><strong>示例：</strong></p><ul><li>例 1： 当前最新价 160，设置 市价达到 169.71，代表当最新价≥169.71 时刻，会进行一笔卖出的委托单。</li><li>例 2： 当前最新价 160，设置 市价达到 150.00，代表当最新价≤150.00 时刻，会进行一笔卖出的委托单。</li></ul><blockquote><p>到价卖出可用于对多头持仓的止盈或止损。</p></blockquote><h2>6. 反弹买入</h2><p>反弹买入（Trailing to Buy）需要先设定一个监控价格。当市场价格突破该监控价格后，系统会根据价格的反弹幅度变化，自动提交您预先设定的委托单。</p><figure class="image image_resized" style="width: 38.8%"><img src="https://pub.pbkrs.com/uploads/2025/ca6db09a5baf10cd5e5e1659a463c69c"/></figure><p><strong>跟踪类型</strong>： </p><ul><li>涨幅：跟踪行情的涨幅百分比；<ul><li>例：1%， 实际反弹超过 1%</li></ul></li><li>涨额 :  跟踪行情的实际涨的价格；  <ul><li>例：1，实际反弹超过 1「币种」</li></ul></li></ul><p><strong>委托单</strong>：实际要报送的订单。</p><p><strong>委托价格 触发时市价＋</strong>： 输入 0，代表以当时的市价委托，输入的数字代表价差。 </p><p>例： 触发时市价＝10 ，「触发时市价＋」=1，则代表系统以 10+1=11 的价格进行委托。 由于反弹买入的行情是不确定的，价差的大小可以用于确保成交。</p><p><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><p><strong>示例：</strong>设置「监控价格」：100  ，「跟踪类型」：涨额  ，「涨额」=10，「委托价格，触发时市价 +」=1，下单 XYZ 标的，下反弹买入单时 市价=100。</p><p>模拟行情波动：</p><ul><li>110- &gt; 105   未满足监控价格条件</li><li>105- &gt; 99     满足监控条件，监控反弹幅度</li><li>99  -&gt; 95      记录下单后最低点  95</li><li>95 -&gt; 104      距离最低点 95 ，反弹涨额 = 9 ，不满足条件，不会触发</li><li>104 -&gt; 90      更新下单后最低点  90</li><li>90 -&gt; 100      距离最低点 90，反弹涨额 = 10 ，满足条件，触发：以当时市价 100 +1 = 101，下达一笔 101 的买入限价单</li></ul><h2>7. 回落卖出</h2><p><strong>回落卖出（Trailing to Sell）</strong>需要先设定一个监控价格。当市场价格突破该监控价格后，系统会根据价格的回落幅度变化，自动提交您预先设定的委托单。</p><p> </p><figure class="image image_resized" style="width: 47.9%"><img src="https://pub.pbkrs.com/uploads/2025/d89a8061519d67ad681aa84bcc3cca46"/></figure><p><strong>跟踪类型</strong>： </p><ul><li>跌幅：跟踪行情的涨幅百分比；<ul><li>例：1%， 实际回落超过 1%</li></ul></li><li><strong> </strong>跌额 ：跟踪行情的实际涨的价格； <ul><li>例：1，实际回落超过 1「币种」</li></ul></li></ul><p><strong>委托单</strong>：实际要报送的订单</p><p><strong>委托价格 触发时市价 -</strong>： 输入 0，代表以当时的市价委托，输入的数字代表价差。 </p><p>例：触发时市价＝10，「触发时市价-」=1，则代表系统以 10-1=9 的价格进行委托。 由于回落卖出的行情是不确定的，价差的大小可以用于确保成交。<br/> </p><p><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><p>示例<strong>：</strong>设置「监控价格」：100  ，「跟踪类型」：跌幅 ，「跌幅」=10%，「委托价格，触发时市价-」=0，下单 XYZ 标的，下回落卖出单时 市价=100。</p><p> </p><p>模拟行情波动：</p><ul><li>90   -&gt;  95         未满足监控价格条件</li><li>95   -&gt;  101       满足监控条件，监控回落幅度</li><li>101 -&gt; 105        记录下单后最高点  105</li><li>105 -&gt; 100        距离最高点 105 ，回落跌幅 = 4.76 % ，不满足条件，不会触发</li><li>100 -&gt; 110        更新下单后最高点  110</li><li>110 -&gt;  99         距离最高点 110 ，回落跌幅 = 10 % ，满足条件，触发：以当时市价 99 - 0 = 99，下达一笔 99 的卖出限价单<br/> </li></ul><p>注：系统会以特定的行情数据（不参考 FINRA 交易所行情）作为行情价格监控标准。例：美股使用全美行情，Basic 行情表现与全美行情有差异。<br/> </p><p><strong>免责声明</strong></p><p><i>市价单是长桥为客户提供的网络便捷交易手段，长桥尽可能提供稳定的服务，但不能保证其绝对可靠。如果出现网络中断、服务器异常等其他物理因素导致市价单未被执行，长桥亦不会承担因此引起的任何损失或损害的责任。</i></p><p><i>预埋订单是长桥证券为客户提供的一项外加功能。在订单发送条件未满足之前，预埋订单将暂时存放于长桥证券的系统之中。然而，由于系统升级、公司行动或其他不可控因素，长桥证券可能会取消系统内的预埋订单。由此可能导致的任何影响，长桥证券不承担相关责任。同时，尽管预埋订单旨在协助客户执行交易计划，但市场波动可能导致订单执行结果与客户预期不符。此外，预埋订单的执行可能受限于网络问题、第三方技术故障或其他不可预见的外部因素。</i></p><p><i>因此，我们建议客户在使用预埋订单功能前充分了解其特性与适用范围，并定期检查和关注其设置的预埋订单，以确保其交易计划不受影响。长桥证券保留对预埋订单功能进行调整或终止的权利，恕不另行通知。</i></p>
