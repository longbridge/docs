<p>长桥综合账户是一个让您能够灵活管理您的投资，并在您需要时利用杠杆进行交易的交易账户。 您可以选择通过指定证券放在您的账户中作为抵押品，通过保证金融资提高您的投资购买力。</p><p>账户的融资额度会根据您存入的现金或者转仓情况自动评估。 如需调整，请登录长桥 App &gt; <strong>资产</strong> &gt; <strong>融资状态</strong>申请，或者联系您的客户经理。</p><h2>1. 保证金</h2><ul><li><strong>初始保证金 (IM)</strong>：建仓时需存入的保证金要求</li><li><strong>维持保证金 (MM)</strong>：股权资产需维持的水平</li><li><strong>平仓保证金 (FM)</strong>：当股权资产低于此水平时， 持仓可能被即时强平</li><li><strong>IM/MM/FM 要求</strong> = 加总 (个人投资产品的市值 x 相应的保证金系数)</li></ul><h2>2. 保证金要求</h2><p><strong>股权资产 </strong>= 现金余额 (分类账) + 投资组合总市值</p><h3>可用资金</h3><ul><li><strong>可用资金（包含融资）</strong>= 股权资产- 初始保证金要求 - 冻结资金</li><li><strong>最大购买力</strong> = 可用资金 / 初始保证金（IM）</li></ul><p>结欠不得超过融资额度。</p><p><strong>示例：</strong></p><blockquote><p>客户存入 $10,000 现金，并购入初始保证金系数 (IM ratio) 为 30% 的股票，账户融资额度为 $20,000</p></blockquote><p>最大购买力 = $10,000 / 30% = $33,333</p><p>假设账户融资额度为$20,000，因此该账户实际最多只能购买$30,000 该股票（$10,000 为现金，$20,000 为融资）。</p><h3>追缴保证金（Margin Call）</h3><p>追缴保证金将会高于维持保证金和股权资产的差额。</p><p>当股权资产低于维持的水平时，本公司会发出追缴保证金通知。 客户必须在收到通知起 3 个交易日内（包括收到通知当日）清缴追缴保证金差额。</p><p><strong>示例：追缴保证金案例</strong></p><blockquote><p>客户存入$10,000 现金及价值$5,000 的 A 股票（IM：30%， MM：25%），并购买了价值$ 25,000 的 B 股票（IM：50%， MM：45%）。 假设 B 股票的市值跌至$19，500。</p></blockquote><p>客户购入股票后，B 股票的市值下跌后，客户持仓为下</p><figure class="table"><table><colgroup><col style="width: 18.32%"/><col style="width: + HKD 19,500 X 45%)</td></tr><tr><th>股权资产</th><td>HKD 9,500</td></tr><tr><th>追缴保证金</th><td>HKD 1,750</td></tr></tbody></table></figure><p>客户需在指定日期或之前使其账户的股权资产达至保证金要求。</p><p>如客户选择卖出证券，所需卖出的市值则不多于初始保证金和股权资产的差额/初始保证金系数 (IM Ratio)</p><p><strong>当股权资产低于强平保证金时，必需立即清缴追缴保证金差额， 否则持仓可能被即时强平。</strong></p><blockquote><p>实际追缴金额可能较高，视乎股票性质和公司政策而定。</p></blockquote><h2>3. 余额资金管理服务</h2><p>您可选择加入余额通管理服务，余额通是长桥证券（香港）有限公司推出的一款闲置资金理财产品。 为客户提供现金增值服务，既满足客户随时买股票的需求，又能为客户的闲置资金创造收益。 加入后，您多余的港币及美元资金将酌情用于投资货币市场基金。</p><p>请参阅长桥 App 中关于余额通的部分获取更多信息。</p><h2>4. 交易结算</h2><p>长桥综合账户将以交易货币进行对应结算。</p><ul><li><strong>买入合约结算：</strong>买入合约将在合约到期日结算。</li><li><strong>卖出合约结算：</strong>卖出合约结算将在履行交货义务后进行。</li></ul><h2>5. 在线交易记录及对账单</h2><p>只要该月有交易行为，月末将提供一份详细的账户月结单。</p><h2>6. 转账汇款</h2><p>详情请参阅 App 中出金入金指引。</p><p> </p><p><strong>关键要点</strong>：</p><ul><li><strong>保证金体系</strong>：<ul><li><strong>初始保证金 (IM)</strong>：开仓最低要求</li><li><strong>维持保证金 (MM)</strong>：持仓警戒线</li><li><strong>平仓保证金 (FM)</strong>：强制平仓阈值</li><li><strong>计算公式</strong>：<strong>股权资产</strong> = 现金余额 (分类账) + 投资组合总市值</li></ul></li><li><strong>杠杆控制</strong>：<ul><li><strong>最大购买力</strong> = 可用资金 / 初始保证金（IM）<strong>可用资金（包含融资）</strong>= 股权资产- 初始保证金要求 - 冻结资金</li><li><strong>可用资金（包含融资）</strong>= 股权资产- 初始保证金要求 - 冻结资金</li></ul></li><li><strong>风控流程</strong>：<ul><li>股权资产＜MM 时，需 3 个交易日内补足差额</li><li>股权资产＜FM 时，可能即时强平</li></ul></li><li><strong>增值服务</strong>：余额通自动投资货币基金，提升闲置资金收益</li></ul><p> </p><p><strong>免责声明</strong></p><p><i>本文仅供参考，不构成任何投资建议。</i></p>
