class="image"><img src="https://pub.pbkrs.com/uploads/2025/f14da416c9c2476b4255cf959ee23460"/></figure><h3>（4）唤起组件工具箱</h3><p>默认为空，需要手动设置，点击可快速唤起组件工具箱</p><figure class="image"><img 则为选中当前操作行为；</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/5959c83e94f922d711326d24ec979bcc"/></figure><h2>3. 交易快捷键</h2><h3>（1）全局通用</h3><p>可全局唤起交易组件买入、交易组件卖出、今日订单弹窗</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/4a51e3fa9824dbfe438ee4789e2d2da3"/></figure><h3>（2）快速下单 - 针对交易组件生效</h3><p>交易快捷键，需要焦点选中交易组件，针对交易组件生效，包括价格填充、数量填充快捷键等。</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/5116a9265ae2396eed17a9d83fc6d0aa"/></figure><h2>4. 快速撤单快捷键</h2><p>订单快捷键，需要焦点选中当日订单/历史订单组件，针对当日订单、历史订单组件生效</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/30e40d8199a136af901f85b8a9bf2254"/></figure><h2>6. 自定义快捷键规则</h2><p>快捷键自定义输入，允许单键和组合键设置。</p><ul><li>单键输入：允许 F1～F12、标点符号等自定义输入设置，其中单个数字或者单个字母等不允许设置</li><li>组合键：<ul><li>Mac：输入 Command、Shift、Option、Control+ 数字、字母或标点符号</li><li>Windows：输入 Ctrl、Shift、Alt+ 数字、字母或标点符号</li><li>其中组合键的位数不做限制，最后一位必须是数字、字母或标点符号</li></ul></li></ul>
