<p><span style="background-color: rgb(255,255,255); color: rgb(15,17,21)">本文介绍了港股轮证的基础知识，涵盖窝轮、牛熊证、界内证三大类产品的命名规则、生命周期、通用行情指标及特有参数，帮助投资者理解轮证交易的核心机制与风险特征。</span></p><h2>1. 轮证各类型基础信息</h2><p>港股轮证分为以下三种大类，其中，窝轮和牛熊证有方向的，界内证无方向。</p><figure class="table"><table><tbody><tr><td><h2>轮证类型</h2></td><td><h2>方向</h2></td><td><h2>名称示例</h2></td><td><h2>命名规则</h2></td></tr><tr><td rowspan="2"><p>窝轮：</p><p>衍生权证 Warrant</p></td><td>看涨</td><td>QQZZ 年月购 A</td><td rowspan="5"><p>QQ - 相关资产</p><p>ZZ - 发行商</p><p>年 - 到期年份</p><p>月 - 到期月份。 1 月至 10 月将以中国数字（一、二…十）代表；11 月及 12 月分别以「甲」及「乙」代表</p><p> </p><p>购 - 认购证</p><p>沽 - 认沽证</p><p>非认购或认沽证（ ）</p><p> </p><p>牛 - 牛证（牛）</p><p>熊 - 熊证（熊）</p><p>界 = 界内证</p><p>A - 同一发行商就同一相关资产再发行同一到期年月的衍生权证，以显示系列编号（A,B,C…）</p><p>* - 以人民币买卖的衍生权证之代表符号</p><p>窝轮 QQZZ 年月 A*</p><p>牛熊 QQZZ 月牛 A*</p></td></tr><tr><td>看跌</td><td>QQZZ 年月沽 A</td></tr><tr><td rowspan="2"><p>牛熊证：</p><p>CBBC for Callable Bull-Bear Contracts</p></td><td>看涨</td><td>QQZZ 年月牛 A</td></tr><tr><td>看跌</td><td>QQZZ 年月熊 A</td></tr><tr><td><p>界内证：</p><p>Inline Warrant</p></td><td>区间价格</td><td>QQZZ 年月界 A</td></tr></tbody></table></figure><h2>2. 轮证生命周期</h2><p>类似普通股票，轮证也会有等待上市、正常交易、终止交易的流程。</p><h2>3. 轮证通用行情字段介绍</h2><h3>街货量 &amp; 街货比</h3><p>街货量：指市场上由其他投资者持有的轮证数量。</p><p>街货比：指市场上由其他投资者持有的轮证占轮证总发行量的比例。</p><h3>换股价 &amp; 换股比率</h3><p><strong>换股比率</strong>是指，多少单位的轮证可以换 1 股正股，兑换时对应正股的价格，称为<strong>换股价</strong>。</p><h3>溢价</h3><p>指投资者以现价买入某轮证并持有至到期时，正股需要上升或下跌多少才能使这笔投资保本。溢价越小，赢的机会就越大。</p><ul><li>认购证 &amp; 牛证的溢价 ＝（最新价×换股比率＋行使价－正股价）/正股价×100％</li><li>认沽证 &amp; 熊证的溢价 ＝（最新价×换股比率－行使价＋正股价）/正股价×100％</li><li>界内：<ul><li>当下限价 &lt;= 正股价格 &lt;= 上限价时，溢价 = 0.00%</li><li>当正股 &lt; 下限价时，溢价 =（下限价 - 正股价）/正股价 x 100%</li><li>当正股 &gt; 上限价时，溢价 =（正股价 - 上限价）/正股价 x 100%</li></ul></li></ul><h3>打和点</h3><p>指当投资者买入并持有轮证到期之前，正股需要涨/跌到多少价格，投资者才可以盈亏平衡。</p><ul><li>认购证 &amp; 牛证打和点 = 行权价 +（最新价 x 换股比率），即 = 行权价 + 换股价</li><li>认沽证 &amp; 熊证打和点 = 行权价 -（最新价 x 换股比率），即 = 行权价 - 换股价</li></ul><h3>杠杆比率</h3><p>杠杆比率是用来衡量投资者买入轮证的价格与正股的市价之比，杠杆比率越高，盈利时的比例或亏损的风险也越大。</p><ul><li>杠杆比率 = 正股价格 /（轮证价格 x 换股比率）</li><li>特别的，界内证的杠杆比率：杠杆比率 = 1 / 界内证价格</li></ul><h2>4. 窝轮的（认股证）特殊字段介绍</h2><h3>引申波幅</h3><p>窝轮在结构上类似期权，引申波幅是指将窝轮价格带入期权定价模型（一般用 BS 定价模型）中，反推得到正股的隐含波动性。</p><h3>对冲值</h3><p>对冲值也称 Delta，公式：Delta =（轮证价格变化 * 换股比率）/ 正股。认购证对冲值由 0 至 1，认沽证对冲值由 -1 至 0，窝轮越价外，对冲值越接近 0。</p><h3>有效杠杆</h3><p>使用中，仅看轮证的杠杆比例可能并不能实际反映杠杆情况，有效杠杆是反映正股价格每变动 1%，窝轮价格的有效理论变幅，与对冲值有关。</p><p>公式：有效杠杆 = 对冲值 x 正股价格 / (轮证价格 x 换股比率)</p><h2>5. 牛熊证的特殊字段介绍</h2><h3>收回价 &amp; 距收回价</h3><p>与其他两种轮证不同，牛熊证具有回收机制。当正股价格触及收回价，牛熊证将立刻停止交易作废。</p><p>距收回价衡量了与正股现价之间的百分比。公式：距收回价 =（正股最新价 - 收回价）/ 收回价×100%</p><p> </p><p><strong>关键要点</strong>：</p><ul><li><strong>产品类型</strong>：港股轮证分为窝轮（看涨/看跌）、牛熊证（带强制收回机制）和界内证（区间波动）三大类。</li><li><strong>核心指标</strong>：通用字段包括街货量、溢价、打和点和杠杆比率。</li><li><strong>特有参数</strong>：<ul><li><strong>窝轮</strong>：引入引申波幅、对冲值和有效杠杆。</li><li><strong>牛熊证</strong>：设有收回价，正股触及即终止交易，需重点关注距收回价风险。</li></ul></li></ul><p style="margin-left: 0px"> </p><p><i>本文仅供参考，不构成任何投资建议。</i></p>
