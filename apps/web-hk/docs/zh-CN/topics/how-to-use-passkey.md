<h2>什么是通行密钥？</h2><p>通行密钥（Passkey）是长桥 App 提供的无密码登录方式。添加后，你可在登录或其他高风险验证场景中，通过设备解锁方式（面容、指纹、密码等）完成身份验证，无需输入密码。</p><ul><li><strong>无需密码即可登录：</strong>以面容／指纹识别代替密码，验证更快捷。</li><li><strong>支持多台设备灵活使用：</strong>通行密钥可跨设备完成快捷登录验证。</li><li><strong>加倍保护账户安全：</strong>密钥不经网络传输，有效抵御网络钓鱼等攻击。</li></ul><h2>如何创建和管理通行密钥</h2><h3>使用前请确认</h3><figure class="table"><table><thead><tr><th>项目</th><th>要求</th></tr></thead><tbody><tr><td>长桥 App 版本</td><td>5.4.0 或以上</td></tr><tr><td>系统版本</td><td>iOS 16 或以上、Android 9 或以上、macOS 13 或以上、Windows 11</td></tr><tr><td>设备设置</td><td>已开启锁屏（密码、指纹或面容）</td></tr></tbody></table></figure><blockquote><p>HarmonyOS 设备暂不支持通行密钥。iPhone 用户请先在系统中开启 <strong>iCloud 钥匙串与自动填充</strong>。</p></blockquote><h3>创建步骤</h3><p><strong>步骤 1：</strong>打开长桥 App，进入 <strong>设置 › 账号与安全</strong>。</p><figure class="image image_resized" style="width: 35%"><img src="https://assets.lbkrs.com/uploads/1_19104_mwkgq0gh0tfeje6h53wh_.jpeg"/><figcaption>设置 › 账号与安全</figcaption></figure><p><strong>步骤 2：</strong>在「密码设置」一栏找到 <strong>通行密钥登录</strong>，点击右边的「去添加」。</p><figure class="image image_resized" style="width: 35%"><img src="https://assets.lbkrs.com/uploads/1_19104_mwkgq0gpo94i22pthds_.jpeg"/><figcaption>通行密钥登录 › 去添加</figcaption></figure><p><strong>步骤 3：</strong>在通行密钥介绍页点击 <strong>添加通行密钥</strong>。</p><figure class="image image_resized" style="width: 35%"><img src="https://assets.lbkrs.com/uploads/1_19104_mwkgq0h5s5xd1vyrn28_.jpeg"/><figcaption>点击「添加通行密钥」</figcaption></figure><p><strong>步骤 4：</strong>系统会弹出加入通行密钥的窗口，点击蓝色按钮 <strong>加入通行密钥</strong> 并以 Face ID／Touch ID 确认。如想存到其他设备，可选「在其他设备上存储」。</p><figure class="image image_resized" style="width: 35%"><img src="https://assets.lbkrs.com/uploads/1_19104_mwkg9edmxo79rcgych9_.jpeg" alt="加入通行密钥并完成验证"/><figcaption>加入通行密钥并完成验证</figcaption></figure><p><strong>步骤 5：</strong>添加成功后，密钥会显示在通行密钥列表，并列出更新时间和设备型号。点击 ✎ 图标可为密钥改名，方便辨认是哪台设备。</p><figure class="image image_resized" style="width: 35%"><img src="https://assets.lbkrs.com/uploads/1_19104_mwkgq0hb6fn5r833b92_.jpeg"/><figcaption>添加成功，可改名或删除</figcaption></figure><h3>删除通行密钥</h3><p>在通行密钥列表点击密钥右上角的删除图标即可。删除后，该密钥即时失效，不能再用于登录长桥账户。系统中对应的记录不会自动移除，如需清理，iOS 18 或以上可在「密码」App 中手动删除。</p><h3>各平台存储与同步方式</h3><h4>iPhone / iPad</h4><ul><li>验证方式：Face ID、Touch ID 或锁屏密码。</li><li>密钥默认存入 iCloud 钥匙串，同一 Apple ID 的其他设备可直接使用。iOS 18 或以上可在「密码」App 中查看和管理。</li><li>也可扫描其他设备显示的二维码、使用 USB／NFC 实体安全密钥，或存入第三方密码管理器。</li></ul><h4>Android</h4><ul><li>验证方式：指纹、面容或锁屏密码。</li><li>已登录 Google 账户并开启同步时，密钥存入 Google 密码管理工具，可在同一 Google 账户的设备上使用。</li><li>未开启 Google 同步时，密钥只保存在本机，换机后需重新创建。部分品牌机型只支持本机存储。</li></ul><h4>Mac</h4><ul><li>验证方式：Touch ID 或 Mac 登录密码。</li><li>密钥经 iCloud 钥匙串同步，需在系统设置的 iCloud「密码与钥匙串」开启同步。</li></ul><h4>Windows</h4><ul><li>验证方式：Windows Hello（面容、指纹或 PIN）。</li><li>密钥可存储在本机，或同步至你的 Microsoft 账户。</li></ul><h2>如何使用通行密钥登录／验证</h2><p>前提：账户已预先添加通行密钥，且你使用的设备及系统版本支持通行密钥。</p><h3>方式一：直接以通行密钥登录</h3><p>在登录页选择以通行密钥登录，系统会自动找出本机或云端已存储的密钥，完成面容／指纹验证即可登录，无需输入账号。若本机没有密钥，可选择扫描另一台设备上的二维码，或使用实体安全密钥。</p><h3>方式二：先输入账号</h3><p>输入长桥账号、手机号码或邮箱后点击下一步，如该账户已添加通行密钥，系统会优先建议使用通行密钥验证，后续步骤与方式一相同。</p><blockquote><p>新设备首次登录时，除通行密钥外，可能仍需完成一次设备验证，以确认是你本人操作。</p></blockquote><h2>通行密钥丢失或无法使用怎么办？</h2><ol><li>关闭通行密钥验证窗口，改用密码或短信验证码登录。</li><li>如使用新设备，请按提示完成设备验证。</li><li>登录后前往 <strong>设置 › 账号与安全 › 通行密钥登录</strong>，删除失效的密钥，再重新添加。</li></ol><p>如怀疑设备遗失或被他人使用，请立即删除该设备的通行密钥，并修改登录密码。如有需要，可联系客户服务协助。</p><h2>常见问题</h2><h3>为什么我无法添加通行密钥？</h3><ul><li>设备未设置锁屏（密码、指纹或面容）。</li><li>所选的第三方密码管理器不支持通行密钥。</li><li>设备型号或系统版本过旧，请参考上方版本要求。</li><li>长桥 App 版本过旧，需为 5.4.0 或以上。</li></ul><h3>换了新手机，为什么旧的通行密钥用不了？</h3><p>跨设备使用需要开启系统的密码云端同步：iPhone 为 iCloud 钥匙串，Google Pixel 及原生 Android 为 Google 密码管理工具，其他品牌设置位置各有不同。部分 Android 机型只支持本机存储，换机后需重新创建通行密钥。</p><h3>为什么登录时没有出现通行密钥选项？</h3><p>可能是此账户或此设备尚未添加通行密钥，或该密钥已被删除。请先以其他方式登录，再到设置中添加。</p><h3>使用 USB 安全密钥时要求设置 PIN，应如何处理？</h3><ul><li>使用密钥厂商提供的管理软件设置。</li><li>部分浏览器或桌面程序会在添加通行密钥时要求设置 PIN，但之后无法在同一位置修改。</li><li>在 Google Chrome 前往「设置 › 隐私和安全 › 安全 › 管理安全密钥」，可创建或更改 PIN。</li></ul><h3>为什么通行密钥验证失败？</h3><ul><li>当前设备没有存储此账户的通行密钥。</li><li>设备重置或系统密钥被删除，导致密钥失效。</li><li>密钥已在长桥 App 删除，但系统中仍保留旧记录。</li><li>选错了属于其他账户的密钥。</li><li>暂时性的网络或服务问题。</li></ul><p>一般可先以密码或短信验证码登录，删除旧密钥后重新添加。</p><h3>开启通行密钥后，原本的密码还能用吗？</h3><p>可以。通行密钥是额外的登录方式，原有登录密码及交易密码保持不变，你随时可改用密码登录。</p>
