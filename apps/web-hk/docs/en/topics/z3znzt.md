<h2>Component Description</h2><h3>Component Introduction</h3><p>Individual component functions, such as charts, market quotes, trading, order components, etc.</p><p>All functions on the Longbridge desktop are available in the form of components. You can view all the functions currently supported by Longbridge from the component toolbox in the upper right corner, including individual stocks, markets, general, trading, assets, and information categories.</p><h3>2. Instructions for Individual Component Operations</h3><h4>2.1 Adding Components</h4><p>A toolbox entry has been added to the upper right corner of the desktop, which gathers all functional components. Users can click to add components and drag them into the current panel.</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw78fkl18vbksu85ek_.jpeg"/></figure><h4>2.2 Component Size Can Be Freely Adjusted</h4><p>The size of each component can be freely adjusted. You can drag and resize the components within the boundary of the component edges.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/60909260e32dc94901ea131281b9aa1e"/></figure><h4>2.3 More Component Operations: Copy, Maximize, Detach, Remove</h4><p>Click the &#34;...&#34; in the upper right corner of each component to access more operations.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/f4d5b7c76b4ef79a9e4488bb016fa441"/></figure><p>(1) Copy: This will copy the current component to create a new component, displayed in a detached window.</p><p>(2) Maximize: Clicking on the component will maximize it to fill the screen. Clicking the restore button in the upper right corner will automatically restore the component to its default size.</p><p>(3) Detach: Clicking detach allows the component to be separated from the current window into an independent component window. This is convenient for keeping a small view while using other software.</p><p>If a component is detached from the current panel or added to the current panel, the component window will display the source panel and will, by default, be linked with the source panel.</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw7eqw7odecxxlc7pi_.jpeg"/></figure><p>(4) Remove: Clicking remove will remove the current component. If it is a system component such as watchlist, stock, market, or trading panel, you can click 'Reset Layout' at the bottom of the component toolbox. Custom layouts are not allowed to be reset.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/f7080dbcd2cb412993c191334d32c2d3"/></figure><h3>3. Component Linkage Instructions</h3><h4>3.1 Custom Linkage Groups</h4><p>Components in the system layout are linked by default, and currently, it does not support setting linkage groups.</p><p>For newly created custom layouts, components are not linked by default. Users need to decide whether to set linkage groups, which are divided into the following groups:</p><p>Default Linkage: All components are linked without setting a group.</p><p>No Linkage: Selected components and subjects are not linked.</p><p>Linkage Group 1, Linkage Group 2, ... Linkage Group 9: After clicking linkage, the component's upper right corner will indicate the current linkage group, and components in the same group will automatically link.</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw7lkzaxcqntgp7fvp_.jpeg"/></figure><h4>3.2 Linkage Parameters</h4><p><strong>Stock Linkage</strong>: When the chart and trading components are set to linkage mode, switching the chart to Stock A will also switch the trading component to Stock A. Currently, most components support this stock linkage.</p><p><strong>Market Linkage</strong>: The market for account assets and holdings is linked by default. For example, if the account assets switch to Hong Kong stocks, the holdings will also switch to Hong Kong stocks.</p><h4>3.3 Unidirectional and Bidirectional Linkage</h4><p><strong>Bidirectional Linkage</strong>: Currently, all linkages are bidirectional. That is, clicking on Component A will cause Component B to follow, and vice versa.</p><p><strong>Unidirectional Linkage</strong>: In unidirectional linkage, clicking on Component A will cause Component B to follow, but clicking on Component B will not cause Component A to follow. There are currently no business scenarios for this, but it may be gradually introduced in the future.</p><h4>3.4 Source Panel Linkage</h4><p>If a component is detached from the current panel or a new component is added to the current panel, the component window will display the current source panel. By default, the component will link with the source panel.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/f6064aaeec8da6a370b9f0b90a81bd44"/></figure><h3>4. Component Header Search</h3><p>The component header includes a search function, categorized as follows:</p><p>Some components have stock-related attributes, such as charts, quote information, and transaction details. When these components with stock-related attributes are detached, the component header automatically includes a stock search function, making it easy to switch stock targets.</p><p>Newly created custom pages with stock-related components have headers that automatically include a search function, making it easy to switch stock targets.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/ee76e6ed0d3bf5ac227ee5a2663a432e"/></figure><h3>5. Component Pinning Operation</h3><p>After a component is detached, clicking on other software or the main window can easily cover the current component. If you need the component to stay on top, you can click the pinning function in the upper right corner of the component to keep it floating on top.</p><p>To unpin the component, click the pinning button again to cancel the top-level positioning.</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw7sljeyllgg8m1aof_.jpeg"/></figure><h2>Layout Description</h2><p>Currently, the desktop layout is mainly divided into two types:</p><p>System Layout: The default layout provided by the system, such as Watchlist, Individual Stocks, Market, Assets, and Stock Picker pages, is considered the system layout;</p><p>System layouts cannot be edited or deleted, but the content and layout of components within the panels can be customized.</p><p>Custom Layout: The layout after opening a new tab, which can be custom named, deleted, etc.;</p><p>Custom layouts are further divided into two types: Adaptive Layout and Canvas Layout;</p><h3>1. System Layout</h3><h4>1.1 Introduction to System Layout</h4><p>The default layout provided by the system, such as Watchlist, Individual Stocks, Market, Assets, and Stock Picker pages, is considered the system layout; system layouts cannot be edited or deleted, but the content and layout of components within the panels can be customized.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/1d83dd81b5520cee182d850a65c2d067"/></figure><h4>1.2 Reset System Layout</h4><p>For system layouts, if the user has modified the layout and wants to revert to the system default layout, they can click the component toolbox in the upper right corner to reset the layout and restore it to the system default layout.</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw7uppszi1d33usxjt_.jpeg"/></figure><h3>2. Custom Layout</h3><p>For newly opened tabs, they are all custom layouts. The specific operations are as follows:</p><p>(1) Click the &#34;+&#34; on the right side of the menu bar to open a new tab.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/2764f8b5d6fe5882ea897e50a429506f"/></figure><p>（2）Currently, custom layouts include two types: Adaptive Layout and Canvas Layout.</p><p>Users can choose according to their needs. The introduction and differences between Adaptive Layout and Canvas Layout are detailed below.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/ae095c5f497fdf50612aa15978d922e1"/></figure><h3>3. Custom Layout - Adaptive Layout</h3><h4>3.1 Features of Adaptive Layout</h4><p>Adjusts the layout size according to the screen size</p><p>If there is only one component in the layout, it will occupy the entire screen</p><p>When resizing one component, it will automatically adjust the size of other components to fit</p><h4>3.2 Operating Instructions</h4><p>(1) Open a new tab and select Adaptive Layout</p><p>(2) The system currently provides various trader templates for adaptive layouts, such as securities trading, day trading, multi-stock layout, etc., which can be used directly or created from scratch.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/d75ed1a303a4b7a929f81e7e8df1d6d0"/></figure><p>(3) Click on the blank layout to directly drag components from the component toolbox into the panel for layout.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/b4a3115d40c38022c2efd8aea76c5c36"/></figure><p>(4) You can also combine various functions mentioned earlier, such as component operations, component linkage, component header search, and component pinning, to perform various joint operations based on your needs.</p><h3>4. Custom Layout - Canvas Layout</h3><h4>4.1 Features of Canvas Layout</h4><p>The canvas size is not limited by the screen; if components exceed the current screen size, you can scroll the canvas up, down, left, and right.</p><p>If there is only one component in the layout, it will still display the current component size by default and will not occupy the entire screen.</p><p>When resizing one component, the current component will not squeeze the size of other components, and components can overlap each other.</p><h4>4.2 Operating Instructions</h4><p>Enter the Canvas Layout, and you can directly drag components from the component toolbox into the canvas layout; you can also summon independent component windows and drag them directly into the canvas layout panel.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/ea7ffa79455cc7ef672b1ace844829a6"/></figure><p>You can click the &#34;X&#34; in the upper right corner of the component to close the component; or click the &#34;...&#34; in the upper right corner of the component and select &#34;Remove Component&#34; to close the component.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/f8182bded680f99fc50d7b45db1475d3"/></figure><h4>4.3 Locking Function</h4><p>After editing the canvas layout, you can click the toolbar in the upper right corner to lock the page layout. Once the page is locked, you can no longer add or move components, which helps prevent accidental layout changes by the user.</p><p>After the page layout is locked, you can also click to unlock the page to remove the layout lock.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/63681c6a5944f300135ce29921d8f6c6"/></figure><h4>4.4 Snapping Function</h4><p>The snapping function is a design tool aimed at helping users align and arrange elements on the canvas more easily. When users move elements on the canvas, the snapping function automatically snaps the elements to the nearest grid lines or other elements, achieving precise alignment. This not only improves design efficiency but also ensures neat and aesthetically pleasing layouts.</p><p>In the canvas layout, the snapping function is enabled by default. If not needed, it can be turned off by clicking.</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw86g0y8wub1hbohon_.jpeg"/></figure><h3>5. Layout Management</h3><p>All layout information customized by users is currently automatically stored in the cloud by the system. If there is a layout loss, users can click on the component toolbox in the upper right corner and select &#34;Layout Management&#34; to retrieve their historical layout data.</p><h4>6.1 Automatic Save by the System</h4><p>For layout modification operations performed by users, the system will automatically save the latest data. If there is data loss, it can be recovered by reading the system archives;</p><p>Currently, the first piece of data by default is the system automatically saves data;</p><figure class="image"><img src="https://assets.lbctrl.com/uploads/1_20114_mfw896o0jydt9ervrvr_.jpeg"/></figure><h4>6.2 Manual Save by Users</h4><p>However, if users want to find more historical layout data, it is recommended that they manually click &#34;Save All Layouts&#34;. Users can then retrieve historical layout data as needed. Currently, manual saving supports up to 20 pieces of data.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/a51effff16169d0ad5b4546d3a6fb2d9"/></figure><h3>7. New Tab Supports Save as My Layout</h3><p>In a newly opened tab, you can right-click on the menu and select &#34;Save as My Layout.&#34; Once saved, you can quickly open it from the layout selection under &#34;My Layouts&#34; for convenient repeated use in the future.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/156f4f4fa28b21151f52e842d48ac301"/></figure>
