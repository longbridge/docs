<p>到期日，若 FCN 挂钩标的<strong>收盘价跌破执行价</strong>、且存续期内<strong>触发过敲入 (Knock-in)</strong>，投资者就会&#34;接票&#34;——按<strong>执行价用本金买入</strong>该标的;<strong>若产品未设敲入界限</strong>，则只看到期日收盘价是否低于执行价，<strong>低于即接票</strong>。</p>
