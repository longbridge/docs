<p style="margin-left: 0cm">This article details the core rules, trigger logic, and ideal scenarios for six advanced order types, designed to meet the need for precise trading in various market conditions.</p><h2>1. Limit Orders</h2><p><strong>Limit orders</strong> need to specify the transaction price, and will only be executed when the market hits the specified price or better. Trading at a better price means that the shares are traded at a price lower than the limit price when being purchased or at a price higher than the limit price when being sold.</p><p><strong>Available trading hours:</strong> 4:00 a.m. - 8:00 p.m. (EST)</p><p><strong>Supported order validity: </strong>Rest-of-day/Good-till-canceled/Good-till-date</p><h2>2. Market Order</h2><p>In the case of a <strong>market order</strong>, the order quantity, rather than the price, must be specified. The order will be submitted at a price higher than the current market price in an effort to ensure that the order can be fully executed at the market price.</p><p><strong>Available trading hours:</strong> 9:30 a.m. - 4:00 p.m. (EST)</p><p><strong>Supported order validity period: </strong>Rest-of-day</p><blockquote><p>Due to the limited market liquidity during pre-market and after-hours sessions, prices may fluctuate greatly; as a result, market orders are only issued after the opening of a normal trading session.</p></blockquote><h2>3. Market-On-Close Order</h2><p>A Market-On-Close order does not require a specified price; only the order quantity needs to be designated. The order will be placed 5 minutes before the market closes, and it will be executed at a price close to the closing price.</p><p><strong>Available trading hours:</strong> 9:30 a.m. - 4:00 p.m. (EST)</p><p><strong>Supported order validity period: </strong>Rest-of-day</p><h2>4. Buy if Touched</h2><p>A trigger price must be set for <strong>buy if touched orders</strong>. When the market price hits the trigger price, the system is required to submit the price (market price/limit price), quantity and other parameters relating to the buy order.<br/> </p><figure class="image image_resized" style="width: 57.8%"><img src="https://pub.pbkrs.com/uploads/2025/cce82468e4f556228a8724bc235b21ed"/></figure><p><br/>Condition: A &#34;trade order&#34; is triggered once the market price reaches the condition set below.</p><p style="margin-left: 0px"><strong>Trigger Price</strong>: The set price must not be equal to the current price. If the set price is greater than the current latest price, it means that the order will be triggered once the latest price rises above the set price. If the set price is less than the current latest price, it means that the order will be triggered once the latest price falls below the set price.</p><p style="margin-left: 0px"><strong>Orders</strong>: The actual order to be submitted.</p><p style="margin-left: 0px"><strong>Order Type</strong>: Limit: Limit order, Market: Market order (no need to enter a price).<br/><br/><strong>Supported order validity: </strong>Rest-of-day/Good-till-canceled/Good-till-date<br/><br/><strong>Examples: </strong><br/><br/>Example 1: The current latest price is 191. Setting the market price to trigger at 190.07 means that a buy order will be executed when the latest price is less than or equal to 190.07.</p><p style="margin-left: 0px">Example 2: The current latest price is 191. Setting the market price to trigger at 191.07 indicates that a buy order will be executed when the latest price is greater than or equal to 190.17.</p><blockquote><p> Buy if Touched  can be used for profit-taking or stop-loss on short positions</p></blockquote><h2>5. Sell if Touched</h2><p>A trigger price must be set for <strong>sell if touched orders</strong>. When the market price hits the trigger price, the system is required to submit the price (market price/limit price), quantity and other parameters relating to the sell order.<br/> </p><figure class="image image_resized" style="width: 56.07%"><img src="https://pub.pbkrs.com/uploads/2025/9e90c6acf2faed01ef5063bba6eb730d"/></figure><p> </p><p>Condition: A &#34;trade order&#34; is triggered when the market price reaches the condition set below.</p><p style="margin-left: 0px"><strong>Trigger Price</strong>:This price should not be equal to the current price. If the set price is greater than the current latest price, it means that once the latest price rises above the set price, it will trigger. If the set price is less than the current latest price, it means that once the latest price falls below the set price, it will trigger.</p><p style="margin-left: 0px"><strong>Orders</strong>: The actual order that is to be submitted.</p><p style="margin-left: 0px"><strong>Order type:</strong> Limit: Limit order, Market: Market order (no need to enter a price).</p><p style="margin-left: 0px"><strong>Supported order validity: </strong>Rest-of-day/Good-till-canceled/Good-till-date</p><p style="margin-left: 0px"><strong>Examples: </strong><br/><br/>Example 1: The current latest price is 160, and if we set the market price to reach 169.71, it means that when the latest price is ≥169.71, a sell trade order will be executed.</p><p style="margin-left: 0px">Example 2: The current latest price is 160, and if we set the market price to reach 150.00, it means that when the latest price is ≤150.00, a sell trade order will be executed.</p><blockquote><p>Sell if Touched can be used for profit-taking or stop-loss on long positions.</p></blockquote><h2>6. Trailing to Buy</h2><p style="margin-left: 0px"><strong>Trailing to Buy</strong> requires setting a monitoring price first. Once the market price breaks through this monitoring price, the system will automatically submit your pre-set order based on the change in the rebound amplitude of the price.</p><figure class="image"><img src="https://pub.pbkrs.com/uploads/2025/6ad089d9503c55170c3809af034c94c8"/></figure><p><br/> </p><p style="margin-left: 0px"><strong>Tracking type</strong>:</p><ul><li>Chg %: This tracks the percentage increase in the market price; for example, 1% means that the actual rebound exceeds 1%.</li><li>Chg: This tracks the actual price increase in the market; for example, 1 (corresponding to the currency) means that the actual rebound exceeds 1 unit of the relevant currency.</li></ul><p style="margin-left: 0px"><strong>Orders</strong>: The actual order that is to be submitted.</p><p style="margin-left: 0px"><strong>Market price +</strong>: Input 0 represents placing an order at the current market price, while the entered number represents the price difference.</p><p style="margin-left: 0px"><strong>Supported order validity: </strong>Rest-of-day/Good-till-canceled/Good-till-date</p><p style="margin-left: 0px"><strong>Examples: </strong></p><p style="margin-left: 0px">Set &#34;Monitoring Price&#34;: 100, &#34;Tracking Type&#34;: Increase Amount, &#34;Increase Amount&#34; = 10, &#34;Order Price, plus at trigger time&#34; = 1, place an order for the XYZ instrument, when placing a rebound buy order, the market price = 100. Simulate market price fluctuations:</p><ul><li>110 -&gt; 105   Does not meet the monitoring price condition</li><li>105 -&gt; 99     Meets the monitoring condition, monitoring the rebound amplitude</li><li>99 -&gt; 95       Record the lowest point after placing the order: 95.</li><li>95 -&gt; 104      The rebound price increase amount from the lowest point of 95 is 9, which does not meet the condition, and therefore will not trigger.</li><li>104 -&gt; 90      Update the lowest point after placing the order to 90.</li><li>90 -&gt; 100      From the lowest point of 90, a rebound price increase amount of 10 meets the set condition. Therefore, a trigger is activated: A buy limit order is placed at a price of 101, which is 1 higher than the current market price of 100.</li></ul><h2>7. Trailing to Sell</h2><p>Trailing to Sell requires setting a monitoring price first. Once the market price breaks through this monitoring price, the system will automatically submit your pre-set order based on the change in the pullback amplitude of the price.</p><figure class="image image_resized" style="width: 39.72%"><img src="https://pub.pbkrs.com/uploads/2025/ee2f8e620cf7c2ed5f112df503a6bfe2"/></figure><p>Tracking type:</p><ul><li>Chg %: This monitors the percentage by which the market price has decreased; for example, 1% indicates that the actual decline has exceeded 1%.</li><li>Chg: This monitors the actual decrease in the market price; for example, 1 (corresponding to the currency unit) means that the actual decline has exceeded 1 unit of the relevant currency.</li></ul><p>Orders: The actual order that is to be submitted.</p><p>Market price -: Input 0 represents placing an order at the current market price, while the entered number represents the price difference.</p><p style="margin-left: 0px"><strong>Supported order validity: </strong>Rest-of-day/Good-till-canceled/Good-till-date</p><p style="margin-left: 0px"><strong>Examples: </strong></p><p>Set &#34;Monitoring Price&#34;: 100, &#34;Tracking Type&#34;: Decrease Amount, &#34;Decrease Amount&#34; = 10%, &#34;Order Price, minus at trigger time&#34; = 0, place an order for the XYZ instrument, when placing a pullback sell order, the market price = 100. Simulate market price fluctuations:</p><ul><li>90 -&gt; 95          Does not meet the monitoring price condition</li><li>95 -&gt; 101        Meets the monitoring condition, monitoring the pullback amplitude</li><li>101 -&gt; 105       Record the highest point after placing the order as 105.</li><li>105 -&gt; 100       The decline from the highest point of 105 is 4.76%, which does not satisfy the set condition, and thus will not trigger.</li><li>100 -&gt; 110     Update the highest point after placing the order to 110.</li><li>110 -&gt; 99     From the highest point of 110, a decline of 10 % meets the set condition. Therefore, a trigger is activated: Place a sell limit order at the then-current market price of 99, minus 0, which means the order is placed exactly at 99.</li></ul><p> </p><p>Remarks: The system will use specific market data as the standard for monitoring market prices(Without reference to FINRA exchange market trends).
