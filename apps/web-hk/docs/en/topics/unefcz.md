<p>购买 FCN 后会出现几种收益情况：</p><p><strong>提前敲出</strong>：任一观察日表现最差标的价格 <strong>≥ </strong>敲出界限。</p><p><strong>收益</strong>：返还全部本金 + 已累计派发的票息，产品提前结束。</p><p><strong>产品到期结束</strong>：</p><p><strong>条件</strong>：产品任一观察日未敲出，且到期时所有标的都在执行价之上<strong>或</strong>(设有敲入界限时)<strong>全程未触发敲入</strong>。</p><p><strong>收益</strong>：返还全部本金 + 整个期限内的所有固定票息。</p><p>触发接票：</p><p><strong>条件：</strong>未敲出，且到期最差标的 &lt; 执行价——无敲入界限时直接判定，有敲入界限时还需已触发敲入。</p><p><strong>收益</strong>：<strong>票息照拿</strong>(整个期限的固定票息)，但本金按<strong>执行价接手股票</strong>，承担下跌损失。</p>
