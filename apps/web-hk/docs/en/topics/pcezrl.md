<h2>1. What is component splicing?</h2><h4>I. Component Splicing Instructions</h4><p>Component Splicing: Usually consists of tabs and corresponding content panels. Currently, the desktop only supports splicing multiple components in the &#34;adaptive layout&#34; mode, and you can view the content of multiple components in one area at the same time by switching Tabs. When clicking to switch Tabs, the corresponding content panel will be displayed, while other component content will be hidden. It can effectively solve the data occlusion problem caused by using multiple components to tile the computer screen too small at the same time.<br/>By using component splicing, you can access and switch different functional component modules in an intuitive and efficient way, improving user experience and interface usability.</p><blockquote><p>前置说明注释：</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/ESs8nWbrjPNbZ8Zb8cFtDygRycnUkQT7.jpg"/></figure></blockquote><h4>II. Main features of Component Splicing</h4><ul><li>Provide clear navigation: Through Tabs, users can easily switch to the required functions or components, thus providing an intuitive navigation experience.</li><li>Save space: Component splicing places multiple component contents on one page area, and displays different contents by switching Tabs, saving page space.</li><li>Avoid page refresh: Since Tab splicing switches and displays content panels on the client, it can avoid refreshing the entire page and provide a smoother interactive experience.</li></ul><h2>2. Component Splicing Operation Instructions</h2><h4>I. Introduction to Shadow Color Blocks</h4><ul><li>Shadow color blocks appear above, below, left, and right of the target component: all indicate that the new component is placed near the target component, and splicing is not performed by default.</li></ul><figure class="table"><table><tbody><tr><td><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/Jz9Bn9ChMwEXXyPD2VkEVG5BQpdLxpxs.jpg"/></figure><p style="text-align: center">Above</p></td><td><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/MkFX56mpB6QLjbLAhpx3biwoA9bCLRNb.jpg"/></figure><p style="text-align: center">Below</p></td><td><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/pdKZ2LDy1EJpA8D1LrVnHybAqTnpYwqr.jpg"/></figure><p style="text-align: center">Left</p></td><td><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/qhYw7Taajba8mkduu3kNTJFF1oFXee6b.jpg"/></figure><p style="text-align: center">Right</p></td></tr></tbody></table></figure><ul><li>When the shadow color block completely occupies the target component, the splicing between the two components can be realized after releasing the mouse. (When component splicing is required, try to move the new component to the middle area of the target component.)</li></ul><p><span style="color: #AAAAAA">The following example is to splice &#34;7*24 News&#34; into the &#34;Chart&#34; component.</span></p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/PsRNXbmweQf8ZRWqkrMEQqqrhyXSX733.jpg"/></figure><h4>II. Splicing of operating components</h4><p>1. Splicing of independent components: When splicing two independent components, you can drag the required component to the target component by holding down the mouse and release the mouse when a blue shadow block appears in the target component. Component splicing can be realized.</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/smw6JAT9rxJWs1xn1p8tB8dLYRYh5xHh.jpg"/></figure><p>2. There are two ways to splice independent components into existing combinations:</p><ul><li><strong>Method 1: </strong>Drag the components that need to be spliced to the target combination. When a blue shadow block appears in the target component, release the mouse to splice. At this time, the new component will be in the last Tab.</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/sRcAEBNPhvS2V8T5AXrbK28XzCzZd5zD.jpg"/></figure><ul><li><strong>Method 2: </strong>Drag the new component to the top tab, and a blue shadow block will appear at the tab position. After letting go, the new component can be spliced into the target group. At this time, the new component will be on the last Tab.</li></ul><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/SCDxbwSrL4MhzKuUnCG6pSLTgMVbQqrt.jpg"/></figure><p>3. Move the spliced components as a whole: Press and hold the blank area of the tabs of the spliced components to move the spliced components as a whole. For placement of shadow color blocks, refer to item 1 of this description.</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/BP8XHTUKgFHfS3kq1qWSYuaLbrDNfqd4.jpg"/></figure><h4>III. Adjust Component Tabs Position</h4><p>Select the component Tab that needs to be moved, hold down the mouse and drag it. When a blue shadow block appears on the target Tab, it means that the component will be moved here after you let go.<br/>(Tips: A thumbnail of the current component will appear under the mouse when dragging. For the thumbnail, refer to the Component Toolbox.)</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/rSLg54gKmYWBCmi9Zqd9u5A6uLDXfqiP.jpg"/></figure><h4>IV. Removing Components From A Composition</h4><p>1. Remove the component into an independent component and use it in the panel: Hold down the Tab of the target component and drag it. When a blue shadow block appears at the moved position, let go and the move will be successful.</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/5pzqhMADvNeGooNWyBw72hhtBhP22cH2.jpg"/></figure><p>2. When a component is no longer needed, it will be removed from the combination: Find &#34;Remove&#34; in the “...” More functions, click to remove the component.</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/kAmBDhNELCQMBhCKGeFzXRC7ShYDGrFa.jpg"/></figure><p>3. When you need to use a component in the combination as an independent window: Find &#34;Detach&#34; in the... more functions and click to detach the component into an independent window for use.</p><figure class="image"><img src="https://pub-canary.lbkrs.com/social/2023/0/ch9oiMpirdf6eY784ekm8KbQ1SUHhzxf.jpg"/></figure><p><strong>Special Note:</strong></p><p>In order to ensure performance and user experience, currently only a maximum of fifteen components can be opened on the same tab page. Using component splicing will occupy the upper limit of components.</p>
