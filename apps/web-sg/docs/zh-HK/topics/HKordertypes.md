<p style="margin-left: 0px">本文將系統介紹港股市場常見的訂單類型，幫助投資者根據不同交易場景選擇合適的下單策略。</p><h4 style="margin-left: 0px">1. 增強限價單（ELO）</h4><p style="margin-left: 0px">有指定價格的限價盤，適用於持續交易時段，可在同一時間與最多 10 條輪候隊伍進行配對，賣盤價可以較最佳買盤價低 9 個價位，輸入買盤價則可以較最佳賣盤價高 9 個價位；配對後任何未能成交的部分將按原先輸入的指定限價轉為一般限價盤，存於所輸入價格的輪候隊伍中。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">2. 市價單（MO）</h4><p style="margin-left: 0px">沒有指定價格的市價單，適用於持續交易時段。市價單的成交價格沒有保證，可能以任何價格成交，配對後任何未能成交的部分系統將直接撤單。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">3. 競價限價單（ALO）</h4><p style="margin-left: 0px">有指定價格的限價盤，適用時段包括早市集合競價及收市集合競價，非以上時段報送此類型訂單，將以預埋單方式於系統暫存，等待下一個集合競價時段報出訂單。若對盤完成，訂單未能獲得全部配對，尚未配對的部分將轉換為下一時段適用類型訂單，繼續留在市場等待對盤成交。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">4. 競價市價單（AO）</h4><p style="margin-left: 0px">沒有指定價格的市價盤，適用時段包括早市集合競價及收市集合競價，且享有較競價限價盤優先的對盤次序，非以上時段報送此類型訂單，將以預埋單方式於系統暫存，等待下一個集合競價時段報出訂單。對盤完成後尚未能配對的競價盤會自動取消。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">5. 到價買入</h4><p style="margin-left: 0px">到價買入（Buy if Touched）需要設定觸發價格以及當市價達到觸發價格後，系統需要提交買入訂單的價格（市價/限價）、數量等參數。</p><p style="margin-left: 0px">支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">6. 到價賣出</h4><p style="margin-left: 0px">到價賣出（Sell if Touched）需要設定觸發價格以及當市價達到觸發價格後，系統需要提交賣出訂單的價格（市價/限價）、數量等參數。</p><p style="margin-left: 0px">支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效<br/> </p><h4 style="margin-left: 0px">7. 反彈買入</h4><p style="margin-left: 0px">反彈買入（Trailing to Buy）需要設定下單後從最低點反彈的價格漲跌數或漲跌幅，以及當市價波動觸發後，系統需要提交買入訂單的下單價差、數量等參數。</p><p style="margin-left: 0px">支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">8. 回落賣出</h4><p style="margin-left: 0px">回落賣出（Trailing to Sell）需要設定下單後從最高點回落的價格漲跌數或漲跌幅，以及當市價波動觸發後，系統需要提交賣出訂單的下單價差、數量等參數。</p><p style="margin-left: 0px">支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><p style="margin-left: 0.0px"><i>本文僅供參考，不構成任何投資建議。</i></p>
