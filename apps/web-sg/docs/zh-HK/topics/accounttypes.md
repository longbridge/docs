<p>Long Bridge Securities Pte. Ltd. 向所有用戶提供一個具有保證金功能的交易帳戶，讓您使用一個帳戶即可交易全球市場。然而，並不是每個人的帳戶都適合開通保證金功能。</p><h3>什麼是長橋 Ace 賬戶？</h3><p><strong>長橋 Ace 賬戶</strong>是一個讓您能夠靈活管理您的投資，並在您需要時利用槓桿進行交易的交易賬戶。 您可以將證券放在您的賬戶中作爲抵押品，通過保證金融資提高您的投資購買力。</p><p>賬戶的默認融資額度爲 0。 如需調整，請登錄長橋 App &gt; <strong>資產 </strong>&gt; <strong>融資狀態</strong>申請。</p><figure class="image image_resized" style="width: 80.56%"><img src="https://assets.lbctrl.com/uploads/1_3622_miee517770vwss4wrbg_.jpeg"/></figure><figure class="image image_resized" style="width: 80.36%"><img src="https://assets.lbctrl.com/uploads/1_3622_miee5enogcxeg4kcqv7_.jpeg"/></figure><h5>保證金</h5><ul><li><strong>初始保證金 (IM)</strong>：建倉時需存入的保證金要求；</li><li><strong>維持保證金 (MM)</strong>：權益資產需維持的水平；</li><li><strong>平倉保證金 (FM)</strong>：當股權資產低於此水平時， 持倉可能被立即強平；</li><li><strong>IM/MM/FM 要求</strong> = 加總 (個人投資產品的市值 x 相應的保證金係數)。</li><li><strong>權益資產 </strong>= 現金餘額 (分類賬) + 投資組合總市值</li></ul><p> </p><h5>可用資金</h5><ul><li><strong>可用資金（包含融資）</strong>= 權益資產- 初始保證金要求 - 凍結資金</li><li><strong>最大購買力</strong> = 可用資金 / 初始保證金（IM）</li></ul><p>欠款不得超過融資額度。</p><p><strong>示例：</strong></p><blockquote><p>客戶存入 $10,000 現金，併購入初始保證金係數 (IM ratio) 爲 30% 的股票，賬戶融資額度爲 $20,000</p></blockquote><p>最大購買力 = $10,000 / 30% = $33,333</p><p>假設賬戶融資額度爲$20,000，因此該賬戶實際最多隻能購買$30,000 該股票（$10,000 爲現金，$20,000 爲融資）。</p><p> </p><h5>追繳保證金（Margin Call）</h5><p>當權益資產低於維持保證金時，本公司會發出追繳保證金通知。 客戶必須在收到通知起 3 個交易日內（包括收到通知當日）清繳追繳保證金差額。</p><p>追繳保證金的金額將略高於維持保證金與權益資產之間的差額，以作爲價格波動的緩衝。</p><p><strong>示例：追繳保證金案例</strong></p><blockquote><p>客戶存入$10,000 現金及價值$5,000 的 A 股票（IM：30%， MM：25%），併購買了價值$ 25,000 的 B 股票（IM：50%， MM：45%）。 假設 B 股票的市值跌至$19，500。</p></blockquote><p>客戶購入股票後，B 股票的市值下跌後，客戶持倉爲下：</p><ul><li><strong>現金欠款: </strong>SGD 15,000 </li><li>(SGD 10,000 - SGD 25,000)</li><li><strong>投資組合總市場價值: </strong>SGD 24,500 </li><li>(SGD 5,000 + SGD 19,500)</li><li><strong>權益資產: </strong>SGD 9,500</li><li><strong>持倉初始保證金: </strong>SGD 11,250 </li><li>(SGD 5,000 X 30% + SGD 19,500 X 50%)</li><li><strong>持倉維持保證金: </strong>SGD 10,025 </li><li>(SGD 5,000 X 25% + SGD 19,500 X 45%)</li><li><strong>追繳保證金: </strong>SGD 1,015 </li><li>(持倉維持保證金與權益資產之間的差額為 SGD 525)</li></ul><p> </p><p>客戶需在指定日期或之前使其賬戶的權益資產達至保證金要求。</p><p>如客戶選擇賣出證券，所需賣出的市值則不少於初始保證金和權益資產的差額/初始保證金係數 (IM Ratio)</p><p><strong>當權益資產低於強平保證金時，必需立即清繳追繳保證金， 否則持倉可能被立即強平。</strong></p><p><i>注：如您在保證金交易機制上需要任何解釋或幫助，請聯繫客服。</i></p><p> </p><h5>交易結算</h5><p>賬戶將以交易貨幣進行對應結算。</p><ul><li><strong>買入合約結算：</strong>買入合約將在合約到期日結算。</li><li><strong>賣出合約結算：</strong>賣出合約結算將在履行交貨義務後進行。</li></ul><p> </p><h5>在線交易記錄及對賬單</h5><p>只要該月有交易行爲或者賬戶有資產，月末將提供一份詳細的賬戶月結單。</p><p> </p><h5>轉賬匯款</h5><p>詳情請參閱 App 中出入金指引。</p><p> </p><p style="margin-left: 0.0px"><i>本文僅供參考，不構成任何投資建議。</i></p>
