<p>本文將快速解答關於餘額通的常見疑問。</p><h4>1. 餘額通適合我嗎？</h4><h5>隨心炒股</h5><p>股票交易不受限制，無需擔心錯過市場機會</p><h5>閒錢增值</h5><p>為閒置資金提供高於活期存款的增值收益，股市休市錢不休。（運用專業的投資管理能力，甄選優質、穩健的投資品種。）</p><h5>一勞永逸</h5><p>一次簽約、自動申購，無需手動。</p><h5>低風險</h5><p>餘額通主要投資於安全性較高的低風險低波動率的高流動基金。在獲取收益的基礎上，滿足投資者資金流動性需求。</p><h3> </h3><h4>2. 餘額通可以直接用於貨幣兌換和出金嗎？</h4><p>如果客戶申請貨幣兌換或還款，則需要手動贖回餘額通內對應幣種的基金。資金贖回回帳後，才能進行貨幣兌換或還款。 然而，若客戶已啟用自動還款功能，系統將在偵測到其他幣種出現借方餘額時，自動贖回餘額通內的相應資金。贖回完成後，所得資金將自動兌換，用於抵銷該幣種的欠款餘額。</p><p> </p><h4>3. 餘額通可以手動贖回嗎？</h4><p>餘額通支持手動贖回，客戶至餘額通頁面可以隨時申請贖回。贖回後可立即用於股票交易，貨幣兌換，出金。贖回的資金最晚 T+1 日到賬。提交贖回後 3 個自然日內贖回款不會自動轉入餘額通。 除此外，餘額通根據你的證券賬戶餘額情況進行自動申購或自動贖回：</p><h5>自動申購</h5><p>僅需設定一次，設定成功後，每日固定時間將現金自動買入餘額通，最低申購金額為 1，零申購費用。資金不閒置。</p><h5>自動贖回</h5><p>餘額通餘額可直接用於股票交易，每日收盤結算後系統將根據您的證券帳戶欠款情況自動贖回餘額通底層的基金進行還款。最低持有份額為 1，零贖回費用。</p><p><strong>免責聲明</strong>：<i>儘管餘額通服務旨在最大化您閒置資金的收益，但請注意，客戶有責任確保帳戶中有足夠的資金用於結算，以防餘額通贖回的資金未能及時到賬，影響交易結算。</i></p><p> </p><h4>4. 餘額通收益是固定嗎？安全嗎？</h4><p>餘額通不保證保本。然而，餘額通旨在產生回報的同時，保持本金價值及維持較高的流動性。所投資的高流動基金分別為針對新元的 <span style="background-color: rgb(250,250,250); color: rgba(0,0,0,0.85)">iFAST SGD Enhanced Liquidity A SGD</span>，以及美元的 <span style="background-color: rgb(250,250,250); color: rgba(0,0,0,0.85)">iFAST USD Enhanced Liquidity USD A</span>。餘額通基金由優質的短期投資工具組成，包括優質的政府和公司債券，商業票據和定期存款。一般到期日不超過 397 天。</p><p> </p><h4>5. 如何計算收益？</h4><p>閒置資金在新加坡交易日上午 08:00 之前轉入，當日（T 日）確認份額。08:00 之後轉入則順延一個交易日。</p><p><strong>舉例</strong>：</p><p style="margin-left: 0px">情景 1：轉入申請時間為週一上午 8:00，則週一就可以確認份額計算收益，在週二可查看收益情况。</p><p style="margin-left: 0px">情景 2：轉入申請時間為週一 15:30，則週二可以確認份額計算收益，在週三可查看收益情况。</p><p> </p><p><strong>免責聲明</strong><br/><i>本文僅作參考，不構成任何投資建議。</i></p>
