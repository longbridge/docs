<p>本文將介紹證券交易中常見的訂單類型及其核心執行規則，涵蓋基礎限價/市價單、條件觸發訂單和特殊執行指令三大類別。</p><h4>1. 限價單</h4><p>限價單需要指定成交價格，只有達到指定價格或更好價格時纔會執⾏。以更好的價格成交是指，買⼊時按比限價更低的價格成交，賣出時以比限價更高的價格成交。</p><p>支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p> </p><h4>2. 市價單</h4><p>沒有指定價格的市價單，適用於持續交易時段。市價單的成交價格沒有保證，可能以任何價格成交，配對後任何未能成交的部分系統將直接撤單。</p><p>支持訂單有效期：當日有效</p><p> </p><h4>3. 到價買入</h4><p>到價買入（Buy if Touched）需要設定觸發價格以及當市價達到觸發價格後，系統需要提交買入訂單的價格（市價/限價）、數量等參數。</p><p>支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p> </p><h4>4. 到價賣出</h4><p>到價賣出（Sell if Touched）需要設定觸發價格以及當市價達到觸發價格後，系統需要提交賣出訂單的價格（市價/限價）、數量等參數。</p><p>支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p> </p><h4>5. 反彈買入</h4><p>反彈買入（Trailing to Buy）需要設定下單後從最低點反彈的價格漲跌數或漲跌幅，以及當價格波動觸發後，系統需要提交買入訂單的下單價差、數量等參數。</p><p>支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p> </p><h4>6. 回落賣出</h4><p>回落賣出（Trailing to Sell）需要設定下單後從最高點回落的價格漲跌數或漲跌幅，以及當價格波動觸發後，系統需要提交賣出訂單的下單價差、數量等參數。</p><p>支持訂單有效期：當日有效 / 撤銷前有效 / 特定日期前有效</p><p> </p><h4>7. 全部成交或立即取消單（FOK）</h4><p>全部成交或立即取消（FOK）是一種有條件生效的訂單，訂單必須立即全部執行或完全不執行。若訂單不能全部執行，則會被取消（killed）。</p><p> </p><h4>8. 立即成交併取消剩餘單（IOC）</h4><p>立即成交併取消剩餘（IOC）是一種買入或賣出證券的訂單，下單後會嘗試立即執行全部或部分訂單，訂單剩餘未執行的部分則會被取消。</p><p> </p><p style="margin-left: 0.0px"><i>本文僅供參考，不構成任何投資建議。</i></p>
