<p>以下是關於追繳保證金的詳細介紹和案例。</p><p><strong>當維持保證金出現虧損時，即當權益資產低於維持保證金要求時，會觸發保證金追繳。客戶需要在收到通知起 3 個交易日內（包括收到通知當日）滿足保證金追繳要求。</strong></p><p>已發出的追加保證金通知金額將略高於維持保證金和權益資產之間的差額，以作爲價格波動的緩衝。</p><p><strong>追加保證金通知的示例：</strong></p><p><span style="color: #888888">客戶存入 10,000 元現金和 5,000 元 A 股（IM：30%，MM：25%）併購買 25,000 新元 B 股（IM：50%，MM：45%）。假設股票 B 的市值跌至 19,500 新元。</span></p><p>客戶買入股票，股票 B 市值下跌後，客戶持倉情況如下。</p><figure class="table"><table><tbody><tr><td><strong>现金欠款</strong></td><td>SGD 15,000 (SGD 10,000 - SGD 25,000)</td></tr><tr><td><strong>投资组合总市场价值</strong></td><td>SGD 24,500 (SGD 5,000 + SGD 19,500)</td></tr><tr><td><strong>权益资产</strong></td><td>SGD 9,500</td></tr><tr><td><strong>持仓初始保证金</strong></td><td>SGD 11,250 (SGD 5,000 X 30% + SGD 19,500 X 50%)</td></tr><tr><td><strong>持仓维持保证金</strong></td><td>SGD 10,025 (SGD 5,000 X 25% + SGD 19,500 X 45%)</td></tr><tr><td><strong>追缴保证金</strong></td><td>SGD 1,015（維持保證金和權益餘額之間的差額爲 SGD 525）</td></tr></tbody></table></figure><p>客戶需要確保其賬戶中的權益資產在指定日期或之前滿足保證金要求。</p><p>如果客戶選擇賣出股票，所需賣出的市值至少等於追加保證金通知金額除以初始保證金比率（<strong>IM 比率</strong>）</p><p><strong>當權益資產低於強平保證金時，客戶需要立即補足追繳金額，否則可能會被強制平倉。</strong></p><p><span style="color: #888888"><i>注意：如果您需要任何關於保證金交易機制的解釋或幫助，請聯繫客服。</i></span></p><p> </p><p style="margin-left: 0px"><strong>關鍵要點</strong>：</p><ul><li>觸發條件：股權資產價值低於維持保證金水平。</li><li>追繳金額：追繳金額通常高於維持保證金與股權資產的差額。</li><li>處理時限：收到通知後需在 3 個交易日內補足資金或減倉。</li></ul><p style="margin-left: 0px"> </p><p style="margin-left: 0px"><strong>免責聲明</strong></p><p style="margin-left: 0px"><i>本文僅供參考，不構成任何投資建議。</i></p>
