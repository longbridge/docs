<h2>1. 個性化推薦服務會使用你的哪些信息？</h2><p>爲了向您展示、推薦相關性更高的信息，提供更契合您要求的服務，我們會收集、使用您的個人信息並通過計算機算法模型自動計算、預測您的偏好，以匹配您可能感興趣的信息或服務，以下我們將向您詳細說明該個性化推薦服務的運行機制以及您實現控制的方式。</p><p>a) 我們提供個性化推薦服務的範圍包括展示圖文或視頻內容，提供搜索結果，推薦內容及服務（包括廣告）等。</p><p>b) 爲了預測您的偏好，我們可能會收集、使用您的設備信息、位置信息以及在使用本平臺時的行爲信息，行爲信息包括您在訪問/使用本平臺時的點擊、關注、收藏、搜索、瀏覽、下載、分享及交易的操作相關記錄。</p><p>c) 我們通過計算機算法對上述信息進行自動分析、計算後提取出您的用戶特徵，再結合其他相關特徵對信息候選池中的內容進行偏好程度的預測，並依據預測的結果對內容進行選取和排序。經過去重、打散等處理後，形成最終的內容推薦列表依次向您展示。</p><p>d) 我們會根據您在使用本平臺過程中的瀏覽行爲對推薦模型進行實時反饋，不斷調整優化推薦結果，更好地向您提供優質內容。</p><p>e)<strong>請您知悉，本平臺中的個性化推薦算法並不會精準識別特定自然人的真實身份，僅是基於用戶行爲和特徵提供相關性更高的信息。</strong></p><p>如果您想了解更多關於個人數據和保護的信息，請參閱我們的<a href="https://support.longbridge.sg/topics/misc/privacy-policy"><span style="color: #304ffe">隱私政策</span></a>。</p><p> </p><h2>2. 關閉個性化推薦服務的效果是什麼？</h2><p>當你選擇關閉個性化內容推薦後，我們不會基於被關閉的個性化推送的目的處理您的個人信息，而僅會向您推送與您的偏好無關的具有普遍性的內容或服務（包括廣告）。 因此你無法享受個性化推薦服務，我們會基於內容熱度等非個性化因素向你展示內容，你可能會看到你不感興趣甚至不喜歡的內容，你的使用體驗可能會受到影響。</p><p>此個性化推送算法功能僅供您個人使用。這是一項爲您提供的增值服務，收集的信息始終是匿名的，不會透露給除您之外的任何人。</p>
