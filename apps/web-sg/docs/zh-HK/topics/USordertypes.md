<p>本文詳細介紹了幾種高級訂單類型的核心規則、觸發邏輯及適用場景，用於滿足不同行情下的精準交易需求。</p><h2 style="margin-left: 0px">1. 限價單</h2><p style="margin-left: 0px"><strong>限價單（Limit Order）</strong>需要指定成交價格，只有達到指定價格或更好價格時才會執⾏。以更好的價格成交是指，買⼊時按比限價更低的價格成交，賣出時以比限價更高的價格成交。</p><p style="margin-left: 0px"><strong>可成交時段：</strong>上午 4 時正至下午 20 時正（美東時間）</p><p style="margin-left: 0px"><strong>支持訂單有效期：</strong>當日有效 / 撤銷前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">2. 市價單</h2><p style="margin-left: 0px"><strong>市價單（Market Order）</strong>不需要指定價格，只需要指定下單數量。訂單會按照高出當時市價的價格提交以盡量保證訂單能夠完全按市價成交。</p><p style="margin-left: 0px"><strong>可成交時段：</strong>上午 9 時 30 分至下午 16 時正（美東時間）</p><p style="margin-left: 0px"><strong>支持訂單有效期：</strong>當日有效</p><p style="margin-left: 0px"><i>因盤前盤後市場流通性有限，價格波動可能較大，因此市價單只會在正常交易時間段開市後發出。</i></p><h2 style="margin-left: 0px">3. 到價買入</h2><p style="margin-left: 0px"><strong>到價買入（Buy if Touched）</strong>需要設定觸發價格以及當市價達到觸發價格後，系統需要提交買入訂單的價格（市價/限價）、數量等參數。</p><p style="margin-left: 0px"><strong>支持訂單有效期：</strong>當日有效 / 撤銷前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">4. 到價賣出</h2><p style="margin-left: 0px"><strong>到價賣出（Sell if Touched）</strong>需要設定觸發價格以及當市價達到觸發價格後，系統需要提交賣出訂單的價格（市價/限價）、數量等參數。</p><p style="margin-left: 0px"><strong>支持訂單有效期：</strong>當日有效 / 撤銷前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">5. 反彈買入</h2><p style="margin-left: 0px"><strong>反彈買入（Trailing to Buy）</strong>需要設定下單後從最低點反彈的價格漲跌數或漲跌幅，以及當市價波動觸發後，系統需要提交買入訂單的下單價差、數量等參數。</p><p style="margin-left: 0px"><strong>支持訂單有效期：</strong>當日有效 / 撤銷前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">6. 回落賣出</h2><p style="margin-left: 0px"><strong>回落賣出（Trailing to Sell）</strong>需要設定下單後從最高點回落的價格漲跌數或漲跌幅，以及當市價波動觸發後，系統需要提交賣出訂單的下單價差、數量等參數。</p><p style="margin-left: 0px"><strong>支持訂單有效期：</strong>當日有效 / 撤銷前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><p style="margin-left: 0px"><strong>注意</strong>：對於條件單，系統以特定行情數據源作為價格監控標準，例如美股基於全美行情進行監控，Basic 行情的表現可能與全美行情存在差異，實際觸發情況請以具體結果為準。</p><p style="margin-left:
