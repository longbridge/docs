<p style="margin-left: 0cm">This article explains the definition, types, rules, and important considerations regarding attached orders.</p><h3>1. Definition of attached orders</h3><p style="margin-left: 0cm">An attached order (also referred to as a child order) is an order that is subordinate to the current order (known as the parent order) and is primarily used to close the position of the parent order. The attached order will be placed only after the parent order is fully filled and the target price is reached.</p><p style="margin-left: 0cm">When you submit the parent order, whether it is a buy order or a short sell order, you can set up attached (child) orders directly via the order interface. By default, the system does not set attached orders (i.e., &#34;None&#34;).</p><figure class="image image_resized" style="width: 80.16%"><img src="https://pub.pbkrs.com/uploads/2025/8b3cff3e0e441fc1707902c3d7ce97f9"/></figure><h3>2. Available types of attached orders</h3><p>Currently, the system supports 3 types of attached orders:</p><h5>Profit Taker Order</h5><ul><li><strong>Take-profit order</strong>: After you set a take-profit attached order, when the parent order is fully filled and the market price reaches the take-profit price, the system will automatically place a limit order with the target price set to the take-profit price. If the parent order is a buy order, the take-profit price must be higher than the parent order price. Conversely, if the parent order is a short sell order, the take-profit price must be lower than the parent order price. The validity period for the attached order can be set to <i>Valid for the day</i>, <i>Good 'til canceled</i>, or <i>Good 'Til Date</i>.</li></ul><figure class="image image_resized" style="width: 80.36%"><img src="https://pub.pbkrs.com/uploads/2025/7cf28d86ece7f96c4f9f18c842c3100c"/></figure><ul><li><strong>Stop order</strong>: After you set a stop attached order, when the parent order is fully filled and the market price reaches the stop-loss price, the system will automatically place a limit order with the target price set to the stop-loss price. If the parent order is a buy order, the stop-loss price must be lower than the parent order price. Conversely, if the parent order is a short sell order, the stop-loss price must be higher than the parent order price. The validity period for the attached order can be set to <i>Valid for the day</i>, <i>Good 'til canceled</i>, or <i>Good 'Til Date</i>.</li></ul><figure class="image image_resized" style="width: 80.56%"><img src="https://pub.pbkrs.com/uploads/2025/d38de627cef1d010f5bbb8bb96ec679f"/></figure><ul><li><strong>Bracket order</strong>: When the parent order is fully filled, if the market price first touches either the take-profit or stop-loss price, the system will automatically submit a limit order with the trigger price as the target price. If the parent order is a buy order, the take-profit price must be higher than the parent order price, and the stop-loss price must be lower than the parent order price. Conversely, if the parent order is a short sell order, the take-profit price must be lower than the parent order price, and the stop-loss price must be higher than the parent order price. The validity period for the attached order can be set to <i>Valid for the day</i>, <i>Good 'til canceled</i>, or <i>Good 'Til Date</i>.</li></ul><figure class="image image_resized" style="width: 80.36%"><img src="https://pub.pbkrs.com/uploads/2025/779fc86d8fe45a9f93f52e525e4c1f8e"/></figure><h3 style="margin-left: 0cm">3. Restrictions on parent order types</h3><p style="margin-left: 0cm">Parent orders can only be buy or short sell orders. A short sell order will be rejected if you hold a sellable position; a buy order will be rejected if you have a short position that needs to be covered.</p><h3 style="margin-left: 0cm">4. Risk control mechanisms</h3><p style="margin-left: 0cm">The risk assessment for an attached order will be executed only after the parent order is fully filled and the attached order's target price is reached. If the attached order exceeds the trading limit or fails the risk assessment, the attached order will not be executed.</p><h3 style="margin-left: 0cm">5. Impact of position changes</h3><p style="margin-left: 0cm">After the parent order is fully filled, the related position will not be frozen. If your position changes due to other trades, a triggered attached order may fail the risk assessment.</p><h3 style="margin-left: 0cm">6. Linkage rules for bracket orders</h3><p style="margin-left: 0cm">When one attached order within a bracket order is canceled or rejected, its paired attached order will be canceled or rejected simultaneously.</p><h3 style="margin-left: 0cm">7. Quantity modification rules</h3><p style="margin-left: 0cm">If you modify the quantity of the parent order before it is fully filled, the quantity of the attached order will be automatically adjusted to match the new amount.</p><h3 style="margin-left: 0cm">8. Restrictions on trading sessions</h3><p style="margin-left: 0cm">Take-profit and stop orders are only triggered during consecutive trading sessions. They will not be triggered overnight, or during pre-market or after hours.</p><h3 style="margin-left: 0cm">9. Processing rules upon expiration</h3><p style="margin-left: 0cm">If the parent order is not fully filled before its expiry date, the attached order will be automatically canceled (without being triggered) upon the expiration of the parent order.</p><h3 style="margin-left: 0cm">10. Order status linkage rules</h3><p style="margin-left: 0cm">When a parent order is canceled, all its attached orders are automatically canceled. When a parent order is deleted, all its attached orders are automatically deleted.</p><p style="margin-left: 0cm"> </p><p style="margin-left: 0cm"><strong>Disclosures</strong></p><p style="margin-left: 0cm"><i>Long Bridge Securities Pte.
