<p style="margin-left: 0px">本文将系统介绍港股市场常见的订单类型，帮助投资者根据不同交易场景选择合适的下单策略。</p><h4 style="margin-left: 0px">1. 增强限价单（ELO）</h4><p style="margin-left: 0px">有指定价格的限价盘，适用于持续交易时段，可在同一时间与最多 10 条轮候队伍进行配对，卖盘价可以较最佳买盘价低 9 个价位，输入买盘价则可以较最佳卖盘价高 9 个价位；配对后任何未能成交的部分将按原先输入的指定限价转为一般限价盘，存于所输入价格的轮候队伍中。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">2. 市价单（MO）</h4><p style="margin-left: 0px">没有指定价格的市价单，适用于持续交易时段。市价单的成交价格没有保证，可能以任何价格成交，配对后任何未能成交的部分系统将直接撤单。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">3. 竞价限价单（ALO）</h4><p style="margin-left: 0px">有指定价格的限价盘，适用时段包括早盘集合竞价及收盘集合竞价，非以上时段报送此类型订单，将以预埋单方式于系统暂存，等待下一个集合竞价时段报出订单。若对盘完成，订单未能获得全部配对，尚未配对的部分将转换为下一时段适用类型订单，继续留在市场等待撮合成交。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">4. 竞价市价单（AO）</h4><p style="margin-left: 0px">没有指定价格的市价盘，适用时段包括早盘集合竞价及收盘集合竞价，且享有较竞价限价盘优先的对盘次序，非以上时段报送此类型订单，将以预埋单方式于系统暂存，等待下一个集合竞价时段报出订单。对盘完成后尚未能配对的竞价盘会自动取消。</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">5. 到价买入</h4><p style="margin-left: 0px"><strong>到价买入（Buy if Touched）</strong>需要设定触发价格以及当市价达到触发价格后，系统需要提交买入订单的价格（市价/限价）、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">6. 到价卖出</h4><p style="margin-left: 0px"><strong>到价卖出（Sell if Touched）</strong>需要设定触发价格以及当市价达到触发价格后，系统需要提交卖出订单的价格（市价/限价）、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">7. 反弹买入</h4><p style="margin-left: 0px"><strong>反弹买入（Trailing to Buy）</strong>需要设定下单后从最低点反弹的价格涨跌数或涨跌幅，以及当市价波动触发后，系统需要提交买入订单的下单价差、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><h4 style="margin-left: 0px">8. 回落卖出</h4><p style="margin-left: 0px"><strong>回落卖出（Trailing to Sell）</strong>需要设定下单后从最高点回落的价格涨跌数或涨跌幅，以及当市价波动触发后，系统需要提交卖出订单的下单价差、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期</strong>：当日有效 / 撤销前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><p style="margin-left: 0.0px"><i>本文仅供参考，不构成任何投资建议。</i></p>
