<h4>总资产 - 资产净值</h4><p><code>总资产净值 = 所有币种现金余额 + 所有市场持仓市值</code>并根据当前选择币种折算展示。</p><blockquote><p><span style="color: #b71c1c">注：如您账户有多个币种或切换其他币种展示查看时，总资产金额可能会受汇率波动增加或减少。例如您持有美元和港元，当总资产使用美元汇总时，港元兑美元的这部分金额会受汇率波动增加或减少。</span></p></blockquote><h4>总资产 - 持仓市值</h4><p>所有市场的股票、基金、衍生品市值总和，并根据当前选择币种折算展示。</p><h4>总资产 - 现金</h4><p><code>现金余额 = 所有币种的 可用余额 + 冻结现金 + 基金/新股预扣（如有）</code></p><h4>总资产 - 当日盈亏</h4><p><code>当日盈亏 = 当前价格 * 当前数量 - 昨日收盘价 * 昨日收盘数量 + 当日卖出成交额 - 当日买入成交额</code></p><p><code>总资产的当日盈亏 = 各市场的当日盈亏相加 </code>并根据当前选择币种折算展示。 代表当日股票市值对比昨日市值的价差</p><blockquote><p>注：如美股开启了盘前盘后，则当日盈亏会按照盘前盘后价格进行计算</p></blockquote><p><a href="https://support.longbridge.sg/topics/Account/intradayPL?locale=zh-CN"><span style="color: #304ffe">点击查看当日盈亏相关案例</span></a></p><h4>总资产 - 持仓盈亏</h4><p><code>持仓盈亏（多头仓位）=（现价 - 成本）* 当前数量</code></p><p><code>持仓盈亏（空头仓位）=（成本 - 现价）* 当前数量</code></p><p><code>总资产的持仓盈亏 = 各市场的持仓盈亏相加</code>并根据当前选择币种折算展示。</p><p>其中成本可以选择<strong>摊薄成本</strong>和<strong>平均开仓成本</strong>，对应的含义分别是：</p><p><strong>摊薄成本：</strong>代表您在开仓至平仓该段持有期内的保本价格，即持有仓位期间每次加仓或减仓都有可能摊高或摊低该成本价。</p><blockquote><p>注：摊薄成本会有负数的情况，如您当日清仓再建仓，那么系统会沿用您清仓前的摊薄成本。</p></blockquote><p><strong>平均开仓成本：</strong>代表持有的仓位对应的成本只考虑加仓情况，不考虑减仓情况。已经减仓的仓位已经转为实现盈亏。</p><p><a href="https://support.longbridge.sg/topics/fundsoverview/PLcost"><span style="color: #304ffe">点击查看持仓盈亏、成本相关案例</span></a></p><h4>总资产 - 应追缴保证金</h4><p>为了避免账户被强制平仓所需要存入或股票变现的最小金额。在缴纳足够的保证金可将风控状态恢复至 “中等风险” 状态，避免被强制平仓的风险。</p><h4>总资产 - 融资欠款</h4><p>融资欠款代表您当前已使用的融资金额，融资金额会产生融资利息，融资利率可在「我的费率」查看。若需还款，请在<strong>资产 </strong>&gt; <strong>现金</strong> &gt; 现金明细进行还款。融资利息按天计算，每月扣款。</p><blockquote><p>注：若您存在融资欠款当天清仓股票还款，需待股票交收完成后才可进行还款。处于交收期股票仍需扣息。</p></blockquote><h4>总资产 - 风控状态</h4><p>衡量您的账户风险状况的指标。风控状态分为 4 个等级：<strong>安全、中等、预警、危险。</strong></p><ul><li><strong>安全</strong>：代表您未使用融资。</li><li><strong>中等</strong>：代表您已使用融资，股权资产大于初始保证金要求。</li><li><strong>预警</strong>：代表您已使用融资，股权资产大于等于初始保证金要求且股权资产大于维持保证金，此时购买力已用尽，不可新增开仓；请关注市场变化，以防账户出现【应追缴保证金】。</li><li><strong>危险</strong>：股权资产小于等于维持保证金要求，在此状态下，您的账户必须根据【应追缴保证金】的数值在当前工作日 14:00 前存入足够的保证金或主动平仓部分头寸提高风控值，否则您的账户会被强制平仓。在补仓截止时之后，券商有权自行决定强卖的股票/价格/数量和时间。请您注意风控状态和杠杆等指标。</li></ul><p> </p><p style="margin-left: 0.0px"><i>本文仅供参考，不构成任何投资建议。</i></p>
