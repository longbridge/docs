<p>Long Bridge Securities Pte. Ltd. 向所有用户提供一个具有保证金功能的交易账户，让您使用一个账户即可交易全球市场。 然而，并不是每个人的账户都适合开通保证金功能。</p><h3>什么是长桥 Ace 账户？</h3><p><strong>长桥 Ace 账户</strong>是一个让您能够灵活管理您的投资，并在您需要时利用杠杆进行交易的交易账户。 您可以将证券放在您的账户中作为抵押品，通过保证金融资提高您的投资购买力。</p><p>账户的默认融资额度为 0。 如需调整，请登录长桥 App &gt; <strong>资产 </strong>&gt; <strong>融资状态</strong>申请。</p><figure class="image image_resized" style="width: 80.76%"><img src="https://pub.pbkrs.com/uploads/2025/cb2a1ae6272bb0141558a87c183fa9ef"/></figure><figure class="image image_resized" style="width: 80.36%"><img src="https://pub.pbkrs.com/uploads/2025/b33b2596842a690842f76675006bdd43"/></figure><h5><strong>保证金</strong></h5><ul><li><strong>初始保证金 (IM)</strong>：建仓时需存入的保证金要求；</li><li><strong>维持保证金 (MM)</strong>：权益资产需维持的水平；</li><li><strong>平仓保证金 (FM)</strong>：当股权资产低于此水平时， 持仓可能被立即强平；</li><li><strong>IM/MM/FM 要求</strong> = 加总 (个人投资产品的市值 x 相应的保证金系数)。</li><li><strong>权益资产 </strong>= 现金余额 (分类账) + 投资组合总市值</li></ul><p> </p><h5><strong>可用资金</strong></h5><ul><li><strong>可用资金（包含融资）</strong>= 权益资产- 初始保证金要求 - 冻结资金</li><li><strong>最大购买力</strong> = 可用资金 / 初始保证金（IM）</li></ul><p>欠款不得超过融资额度。</p><p><strong>示例：</strong></p><blockquote><p>客户存入 $10,000 现金，并购入初始保证金系数 (IM ratio) 为 30% 的股票，账户融资额度为 $20,000</p></blockquote><p>最大购买力 = $10,000 / 30% = $33,333</p><p>假设账户融资额度为$20,000，因此该账户实际最多只能购买$30,000 该股票（$10,000 为现金，$20,000 为融资）。</p><p> </p><h5><strong>追缴保证金（Margin Call）</strong></h5><p>当权益资产低于维持保证金时，本公司会发出追缴保证金通知。 客户必须在收到通知起 3 个交易日内（包括收到通知当日）清缴追缴保证金差额。</p><p>追缴保证金的金额将略高于维持保证金与权益资产之间的差额，以作为价格波动的缓冲。</p><p><strong>示例：追缴保证金案例</strong></p><blockquote><p>客户存入$10,000 现金及价值$5,000 的 A 股票（IM：30%， MM：25%），并购买了价值$ 25,000 的 B 股票（IM：50%， MM：45%）。 假设 B 股票的市值跌至$19，500。</p></blockquote><p>客户购入股票后，B 股票的市值下跌后，客户持仓为下：</p><ul><li><strong>现金欠款: </strong>SGD 15,000 <br/>(SGD 10,000 - SGD 25,000)</li><li><strong>投资组合总市场价值: </strong>SGD 24,500 <br/>(SGD 5,000 + SGD 19,500)</li><li><strong>权益资产: </strong>SGD 9,500</li><li><strong>持仓初始保证金: </strong>SGD 11,250 <br/>(SGD 5,000 X 30% + SGD 19,500 X 50%)</li><li><strong>持仓维持保证金: </strong>SGD 10,025 <br/>(SGD 5,000 X 25% + SGD 19,500 X 45%)</li><li><strong>追缴保证金: </strong>SGD 1,015 <br/>(持仓维持保证金与权益资产之间的差额为 SGD 525)</li></ul><p> </p><p>客户需在指定日期或之前使其账户的权益资产达至保证金要求。</p><p>如客户选择卖出证券，所需卖出的市值则不少于初始保证金和权益资产的差额/初始保证金系数 (IM Ratio)</p><p><strong>当权益资产低于强平保证金时，必需立即清缴追缴保证金， 否则持仓可能被立即强平。</strong></p><p><i>注：如您在保证金交易机制上需要任何解释或帮助，请联系客服。</i></p><p> </p><h5><strong>交易结算</strong></h5><p>账户将以交易货币进行对应结算。</p><ul><li><strong>买入合约结算：</strong>买入合约将在合约到期日结算。</li><li><strong>卖出合约结算：</strong>卖出合约结算将在履行交货义务后进行。</li></ul><p> </p><h5><strong>在线交易记录及对账单</strong></h5><p>只要该月有交易行为或者账户有资产，月末将提供一份详细的账户月结单。</p><p> </p><h5><strong>转账汇款</strong></h5><p>详情请参阅 App 中出入金指引。</p><p> </p><p style="margin-left: 0.0px"><i>本文仅供参考，不构成任何投资建议。</i></p>
