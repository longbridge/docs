<p>本文详细介绍了几种高级订单类型的核心规则、触发逻辑及适用场景，用于满足不同行情下的精准交易需求。</p><h2 style="margin-left: 0px">1. 限价单</h2><p style="margin-left: 0px"><strong>限价单（Limit Order</strong>）需要指定成交价格，只有达到指定价格或更好价格时才会执⾏。以更好的价格成交是指，买⼊时按比限价更低的价格成交，卖出时以比限价更高的价格成交。</p><p style="margin-left: 0px"><strong>可成交时段</strong>：4:00 AM - 20:00 PM（美东时间）</p><p style="margin-left: 0px"><strong>支持订单有效期</strong>：当日有效 / 撤销前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">2. 市价单</h2><p style="margin-left: 0px"><strong>市价单（Market Order)</strong> 不需要指定价格，只需要指定下单数量。订单会按照高出当时市价的价格提交以尽量保证订单能够完全按市价成交。</p><p style="margin-left: 0px"><strong>可成交时段：</strong>9:30 AM - 16:00 PM（美东时间）</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效</p><blockquote><p style="margin-left: 0px"><i>因盘前盘后市场流通性有限，价格波动可能较大，因此市价单只会在正常交易时间段开盘后发出。</i></p></blockquote><h2 style="margin-left: 0px">3. 到价买入</h2><p style="margin-left: 0px"><strong>到价买入（Buy if Touched）</strong>需要设定触发价格以及当市价达到触发价格后，系统需要提交买入订单的价格（市价/限价）、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">4. 到价卖出</h2><p style="margin-left: 0px"><strong>到价卖出（Sell if Touched）</strong>需要设定触发价格以及当市价达到触发价格后，系统需要提交卖出订单的价格（市价/限价）、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">5. 反弹买入</h2><p style="margin-left: 0px"><strong>反弹买入（Trailing to Buy）</strong>需要设定下单后从最低点反弹的价格涨跌数或涨跌幅，以及当市价波动触发后，系统需要提交买入订单的下单价差、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><h2 style="margin-left: 0px">6. 回落卖出</h2><p style="margin-left: 0px"><strong>回落卖出（Trailing to Sell）</strong>需要设定下单后从最高点回落的价格涨跌数或涨跌幅，以及当市价波动触发后，系统需要提交卖出订单的下单价差、数量等参数。</p><p style="margin-left: 0px"><strong>支持订单有效期：</strong>当日有效 / 撤销前有效 / 特定日期前有效</p><p style="margin-left: 0px"> </p><p style="margin-left: 0px"><strong>注意</strong>：对于条件单，系统以特定行情数据源作为价格监控标准，例如美股基于全美行情进行监控，Basic 行情的表现可能与全美行情存在差异，实际触发情况请以具体结果为准。</p><p style="margin-left: 0px"> </p><p style="margin-left: 0px"><strong>免责声明</strong></p><p style="margin-left: 0px"><i>市价单是长桥为客户提供的网络便捷交易手段，长桥尽可能提供稳定的服务，但不能保证其绝对可靠。如果出现网络中断、服务器异常等其他物理因素导致市价单未被执行，长桥亦不会承担因此引起的任何损失或损害的责任。</i></p><p style="margin-left: 0px"><i>预埋订单是长桥证券为客户提供的一项外加功能。在订单发送条件未满足之前，预埋订单将暂时存放于长桥证券的系统之中。然而，由于系统升级、公司行动或其他不可控因素，长桥证券可能会取消系统内的预埋订单。由此可能导致的任何影响，长桥证券不承担相关责任。同时，尽管预埋订单旨在协助客户执行交易计划，但市场波动可能导致订单执行结果与客户预期不符。此外，预埋订单的执行可能受限于网络问题、第三方技术故障或其他不可预见的外部因素。</i></p><p style="margin-left: 0px"><i>因此，我们建议客户在使用预埋订单功能前充分了解其特性与适用范围，并定期检查和关注其设置的预埋订单，以确保其交易计划不受影响。长桥证券保留对预埋订单功能进行调整或终止的权利，恕不另行通知。</i></p>
