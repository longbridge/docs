<p>本文将介绍证券交易中常见的订单类型及其核心执行规则，涵盖基础限价/市价单、条件触发订单和特殊执行指令三大类别。</p><h4>1. 限价单</h4><p>限价单需要指定成交价格，只有达到指定价格或更好价格时才会执⾏。以更好的价格成交是指，买⼊时按比限价更低的价格成交，卖出时以比限价更高的价格成交。</p><p>支持订单有效期：当日有效 / 撤销前有效 / 特定日期前有效</p><p> </p><h4>2. 市价单</h4><p>没有指定价格的市价单，适用于持续交易时段。市价单的成交价格没有保证，可能以任何价格成交，配对后任何未能成交的部分系统将直接撤单。</p><p>支持订单有效期：当日有效</p><p> </p><h4>3. 到价买入</h4><p>到价买入（Buy if Touched）需要设定触发价格以及当市价达到触发价格后，系统需要提交买入订单的价格（市价/限价）、数量等参数。</p><p>支持订单有效期：当日有效 / 撤销前有效 / 特定日期前有效</p><p> </p><h4>4. 到价卖出</h4><p>到价卖出（Sell if Touched）需要设定触发价格以及当市价达到触发价格后，系统需要提交卖出订单的价格（市价/限价）、数量等参数。</p><p>支持订单有效期：当日有效 / 撤销前有效 / 特定日期前有效</p><p> </p><h4>5. 反弹买入</h4><p>反弹买入（Trailing to Buy）需要设定下单后从最低点反弹的价格涨跌数或涨跌幅，以及当价格波动触发后，系统需要提交买入订单的下单价差、数量等参数。</p><p>支持订单有效期：当日有效 / 撤销前有效 / 特定日期前有效</p><p> </p><h4>6. 回落卖出</h4><p>回落卖出（Trailing to Sell）需要设定下单后从最高点回落的价格涨跌数或涨跌幅，以及当价格波动触发后，系统需要提交卖出订单的下单价差、数量等参数。</p><p>支持订单有效期：当日有效 / 撤销前有效 / 特定日期前有效</p><p> </p><h4>7. 全部成交或立即取消单（FOK）</h4><p>全部成交或立即取消（FOK）是一种有条件生效的订单，订单必须立即全部执行或完全不执行。若订单不能全部执行，则会被取消（killed）。</p><p> </p><h4>8. 立即成交并取消剩余单（IOC）</h4><p>立即成交并取消剩余（IOC）是一种买入或卖出证券的订单，下单后会尝试立即执行全部或部分订单，订单剩余未执行的部分则会被取消。</p><p> </p><p style="margin-left: 0.0px"><i>本文仅供参考，不构成任何投资建议。</i></p>
